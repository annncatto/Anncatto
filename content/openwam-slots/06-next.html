补充数据 · 任务纠偏Additional demonstrations · correcting task behavior

前面的误投记录已经完成抓取、抬起、搬运和释放，错误发生在绿色积木的目标篮子选择。新增示范要补足的正是这一任务目的：物体出现在与原示教差异较大的条件下，仍按“蓝色进左篮、绿色进右篮”执行。

The preceding failed rollout completes grasping, lifting, transport, and release; the error is the destination chosen for a green block. The additional demonstrations target this task requirement: under conditions that differ substantially from the original demonstrations, blue objects should still go left and green objects right.

因此，本轮比较关注的是补充数据能否改写目标选择，同时保留已经学到的抓放能力。训练收敛速度、轨迹拟合和目标篮子正确率分别描述这三个过程中的不同结果。

The comparison asks whether additional data can change destination selection while retaining learned manipulation skills. Convergence speed, trajectory fit, and correct-basket rate describe different outcomes in that process.

目标选择的学习Learning destination selection

任务指令先由冻结的 umT5 编码，视频和动作 DiT 再通过条件注意力读取文本与当前状态，并结合图像生成动作。微调仍能改变这些读取条件、融合视觉和输出动作的参数，因此可以在保留语言编码器的同时重新学习“看到什么物体，应送往哪里”。

Frozen umT5 first encodes the instruction. Video and action DiTs read text and current-state context through conditional attention and combine them with images to generate actions. Fine-tuning can update condition reading, visual fusion, and action generation, allowing the object-to-destination mapping to change while retaining the language encoder.

本次监督由视频和动作的 flow matching 构成，正确投放通过示范中的搬运轨迹和释放位置体现。对于错篮问题，新增示范需要让正确目标选择在原来容易出错的条件下反复出现，才能持续向这些可训练模块提供纠偏梯度。

Supervision consists of video and action flow matching; correct placement is represented by demonstrated transport trajectories and release locations. Correct destinations must recur under the conditions that previously produced errors so that the trainable modules repeatedly receive gradients supporting the correction.

  • 语言条件：原 115 回合和新增 40 回合都使用同一句颜色分类指令。新增数据主要监督同一任务在不同条件下的执行；若要进一步检验“改变指令就改变分类规则”，还需同一场景配不同指令的对照。

    Language condition: the original 115 and additional 40 episodes all use the same sorting instruction. The added data mainly supervises the same task under different conditions; testing whether changing the instruction changes the rule additionally requires matched scenes with different instructions.

  • 纠偏数据占比：新增 40 回合占本轮训练帧的 28.24%，按有效样本打乱读取。A 先在旧数据上学习 10k 步，再以约 72% 旧帧、28% 新帧的混合分布继续训练；新示范既要教会新增条件，也要调整已经形成的视觉—动作关联。[17]

    Correction-data share: the additional 40 episodes contribute 28.24% of training frames under shuffled sample loading. A first learns from the original data for 10k updates, then trains on approximately 72% original and 28% added frames; the new examples must both cover new conditions and modify established visual–action associations.

  • 标签一致性：原示范本身符合任务时，应保留有用的抓放轨迹，并增加关键纠偏条件的训练占比。如果原示范在相同条件下也教过错误篮子，应先筛选或修正这部分标签，让新旧监督朝同一任务目标收敛。

    Label consistency: when original demonstrations satisfy the task, useful manipulation trajectories can be retained while increasing exposure to critical correction conditions. If original examples teach a wrong basket under matching conditions, those labels should first be filtered or corrected so both data sources support the same objective.

结果与路线选择Results and route selection

前 100 步动作 loss 均值为 A 0.0287、B 1.3841，A 的任务初始化显著缩短早期适配。到 10k 步，两组在原分布上的指标已经接近，且不同指标给出的排序有所不同。

Mean action loss over the first 100 updates is 0.0287 for A and 1.3841 for B, showing much faster early adaptation from the task model. At 10k updates, original-distribution metrics are close, with different metrics producing different rankings.

这组验证直接支持 A 的早期收敛优势，以及两组对旧轨迹相近的拟合。新增 40 回合全部参加训练，已保存的三条补充数据闭环记录均对应 A；两条路线的纠偏选择应落到相同颜色—位置组合中的抓取完成率与目标篮子正确率。

This validation directly supports A's early-convergence advantage and similar fitting of original trajectories by both runs. All 40 added episodes participate in training, and the three saved expanded-data rollouts all use A; selecting a route for correction calls for grasp-completion and correct-basket rates on matched color–position combinations.

  • 本例优先路线：原模型已展示可复用的抓放能力，目标选择所经过的视频和动作 DiT 也都可以更新，适合先进行有针对性的联合微调。具体做法是保留这些能力，并通过筛选一致的示范、提高关键纠偏条件的采样占比，让新的任务关联得到充分训练。

    Preferred route for this case: targeted joint fine-tuning. The original model demonstrates reusable manipulation skills, and both DiTs involved in destination selection remain trainable. Retain those skills while providing consistent demonstrations and sufficient sampling of critical correction conditions.

  • 重训的作用：从官方基座重训可以移除旧 115 回合形成的任务适配，再从最终混合数据建立对应关系，用来检验旧任务适配是否妨碍纠偏。如果在同样的数据权重和执行条件下，重训稳定提高新增场景的正确篮子率，就优先采用重训模型。

    Role of restarting: test whether prior task adaptation impedes correction. Restarting from the official foundation removes specialization learned from the original 115 episodes and rebuilds the mapping from the final mixture. Prefer the restarted model if it consistently improves correct-basket rate under matched data weighting and execution conditions.

  • 本轮判断：数据分布差异大，需要更充分的纠偏监督；是否重训取决于旧任务适配的实际影响。当前两套配置中，A 已显示节省早期适配的收益，B 提供重新建立任务关联的对照，最终按误投条件下的任务结果选模型。

    Decision from this comparison: a large distribution shift calls for sufficient corrective supervision; restarting depends on the effect of prior task adaptation. A already shows an early-adaptation benefit, while B provides a control that rebuilds task associations. Final model selection follows task outcomes under the observed wrong-basket conditions.

输入统计与更新精度Input statistics and update precision

比较训练起点时，还需控制输入坐标和参数更新方式。两组都重算 min/max，而 A 继承的状态投影原先适配的是旧统计；同一个物理状态因此可能成为不同的条件特征。

Comparing initializations also requires controlling input coordinates and parameter updates. Both runs refit min/max, but A's inherited state projection was previously adapted to the original statistics, so the same physical state can produce a different condition feature.

以 $h_s=W_sN(s)+b_s$ 为状态投影，每回合均匀选取 8 个真实状态，将存储权重转成 FP32，只替换归一化统计或投影权重。旧训练回合得到 872 帧，补充回合得到 320 帧，比较整批投影输出的相对 L2 变化。

For state projection $h_s=W_sN(s)+b_s$, eight real states are sampled uniformly per episode. Stored weights are evaluated in FP32, replacing either normalization statistics or projection weights alone, giving 872 original-training and 320 added states for batchwise relative-L2 comparisons.

两组参数和 Adam 一、二阶动量均保存为 BF16。后续可分别控制近常量状态的归一化尺度，以及 FP32 权重／动量配合 BF16 计算的更新方式，再比较目标篮子正确率，从而区分输入坐标、更新精度与训练起点的作用。

Both runs store parameters and Adam first/second moments in BF16. Separate controls for near-constant-state normalization and FP32 weights/moments with BF16 computation can compare correct-basket rate while distinguishing input coordinates, update precision, and initialization.
