Motion and Reach运动与可达性

“Start gait” runs a stationary-body foot cycle for the legged models. During stance the foot moves backward relative to the body; during swing it lifts and returns forward. The quadruped alternates diagonal pairs, while the biped alternates legs. Each foot target is converted to joint angles by the same two-link inverse kinematics. Changing link lengths changes which targets are reachable and how much each joint must rotate.

“开启步态”会为腿部模型运行原地足端循环。支撑段中，足端相对机身向后；摆动段中，足端抬起并向前返回。四足按对角肢体交替，双足按左右腿交替。每个足端目标都通过相同的二连杆逆运动学转换为关节角。改变连杆长度，会改变目标可达性与各关节需要转动的幅度。

For the arm, drag the green end target in the joint motion plane. With target $(x,y)$ measured from the root, its two inverse branches satisfy:

机械臂可以在关节运动平面内拖动绿色末端目标。以根部为原点，目标为 $(x,y)$ 时，两支逆解满足：

$$\begin{aligned}c_2&=\frac{x^2+y^2-l_1^2-l_2^2}{2l_1l_2},\\q_2&=\pm\arccos c_2,\\q_1&=\operatorname{atan2}(y,x)-\operatorname{atan2}(l_2\sin q_2,l_1+l_2\cos q_2).\end{aligned}$$

The geometric reach condition is $|l_1-l_2|\le\sqrt{x^2+y^2}\le l_1+l_2$. Equal lengths can reach the root; unequal lengths create an inner unreachable region. The studio keeps the current elbow branch and projects an unreachable target to the nearest radial boundary. Joint limits, collisions, support contact and balance would further restrict a real robot’s motion. The gait and arm demonstrations solve kinematics, while the metric panel evaluates the stated mechanical model.

几何可达条件为 $|l_1-l_2|\le\sqrt{x^2+y^2}\le l_1+l_2$。等长连杆可以到达根部，不等长则产生内侧不可达区域。页面保持当前肘部弯曲分支，并将不可达目标投影到最近的径向边界。真实机器人的运动，还受关节限位、碰撞、支撑接触与平衡限制。步态和末端拖动求解运动学，指标面板则计算已说明的力学模型。

Reading the Metrics指标如何理解

Total mass sums the body/accessory allowance, all repeated limbs, actuator packages and end pieces. Each limb uses two uniform members. The distal actuator housing sits at the first member’s end in the joint-mounted layout and on the body in the proximal layout. Remote transmission adds a 0.16 kg allowance per limb, distributed along the first member. Rotor inertia is fixed at $2.5\times10^{-5}$ kg·m² and contributes ideal diagonal $N^2J_m$ terms to the limb mass matrix.

总质量包含机身与附件预算、全部重复肢体、电机模组和端部件。每条肢体使用两根均匀杆件。关节安装方案将第二电机壳体放在第一杆末端，近端方案将其移至机身；每条肢体还增加 0.16 kg 传动预算，沿第一杆分布。转子惯量固定为 $2.5\times10^{-5}$ kg·m²，以理想对角项 $N^2J_m$ 计入单肢质量矩阵。

The displayed $M_{11}$ describes one limb’s root-joint inertia at the shown posture, with the other joint rate set to zero in the kinetic-energy interpretation. It is not the whole robot’s inertia about its body. The static joint torques combine limb gravity with the specified downward end force. They represent the demanded torque, so a larger number is not an improvement in actuator capability.

$M_{11}$ 表示显示姿态下单条肢体的根关节惯量；按动能理解，相应比较将另一关节速度置零。它与整机绕机身的惯量不同。静态关节力矩合并肢体重力与指定的竖直向下末端力，表示所需转矩，数值增大并不代表电机能力改善。

Bending stiffness, stress, tip displacement and the frequency estimate use the longer member as a separate linear cantilever with the specified transverse tip load. For the frequency, the upper member carries an assumed lower-member and end mass, plus the distal motor when present; the lower member carries the end mass. This is a screening estimate. Joint compliance, body motion and coupled modes require an assembled structural model. The deformation view enlarges the analytical curve and shows its scale.

弯曲刚度、应力、末端挠度与频率估计，将较长单根杆件单独视为线性悬臂梁，施加指定横向末端载荷。估计频率时，上杆的假定端部质量包含下杆、端部件及仍位于远端的电机；下杆则包含端部件。这是初步筛选模型。接头柔度、机身运动和耦合模态，需要装配结构模型；挠曲视图会放大解析曲线，并标出倍率。

Material properties are rounded teaching values. The CFRP option is an equivalent laminate with stated effective properties; real directions, layups and failure allowables must be supplied for a component design. A change of material preserves the chosen geometry, so it compares that geometry directly. The material-index plots instead compare minimum-mass designs under their specified geometric scaling. These are two useful, different questions.

材料使用取整后的教学代表值。CFRP 选项采用明确的等效层合板性能，实际部件仍需给出方向、铺层和失效许用值。切换材料保留当前几何，直接比较这套几何的表现；材料指数图则按指定几何缩放规则，比较满足相同约束的最小质量设计。两者回答不同的设计问题。

JSON exports dimensions and analytical results in SI units. GLB exports the displayed geometry and materials; PNG captures the view. URDF exports the simplified rigid-body structure and inertial properties at zero pose, using continuous joints because travel and motor ratings are unspecified. Rotor armature, collision shapes, contacts and controller settings need separate definition before simulation.

JSON 导出 SI 单位下的尺寸与解析结果；GLB 导出显示的几何和材质，PNG 保存视图。URDF 导出零位的简化刚体结构与惯性参数，因为没有指定行程和电机额定值，使用连续关节。开展仿真前，还需要补充转子 armature、碰撞形状、接触和控制器设置。

Further Reading继续阅读

This page runs in the browser and can be embedded in a static blog. Geometry, planar inverse kinematics and these analytical metrics require no backend. Full contact dynamics, detailed finite-element analysis or controller optimization need an appropriate solver and a more complete model. A solver can run locally, in a browser runtime or through a service, depending on its cost and dependencies.

页面在浏览器中运行，可以嵌入静态博客。几何、平面逆运动学与这些解析指标都不需要后端。完整接触动力学、详细有限元或控制器优化，需要适合的求解器和更完整的模型；依据计算量和依赖，可以在本机、浏览器运行时或服务端执行。
