Task, State and Noise Conditions任务、状态与噪声条件

What task, from which robot state任务目标与机器人起始状态

The frozen umT5 encoder maps the instruction into 4096-D text features. A learned projection converts the current 80-D state $q$ into one additional context token. The resulting context $c$ is read by both streams through their own per-block cross-attention.冻结的 umT5把指令编码为 4096 维文本特征；可学习投影把当前 80 维状态 $q$ 转为一个附加上下文 token。合并后的上下文 $c$ 由两流各自的逐层交叉注意力读取。

Language specifies the intended change; proprioception tells the action network where the robot starts. The clean visual prefix supplies the current scene.语言指定期望发生的变化，本体状态提供机器人从哪里开始运动，干净视觉前缀则提供当前场景。

Where a token is, how noisy it istoken 在哪里、含有多少噪声

RoPE supplies sequence position: a 3D video grid or a 1D action index. AdaLN uses noise embeddings to modulate the scale and shift of normalized features. It conditions each stream on its own noise time, $t_v$ or $t_a$, so the same weights can process different noise levels. Observed-frame tokens stay at the clean endpoint $t_v=1$.RoPE提供序列位置：视频的三维网格或动作的一维序号。AdaLN根据噪声嵌入调节归一化特征的缩放与偏移，向各流注入各自的噪声时间 $t_v$、$t_a$，使同一组参数能够处理不同噪声水平；当前观测 token 始终处于干净端点 $t_v=1$。

Noise time is a generation coordinate: 0 means noise and 1 means data. It is distinct from a video-frame index and the robot’s physical control time.噪声时间是生成过程的坐标：0 表示噪声，1 表示数据；它与视频帧序号、机器人的物理控制时间分别承担不同作用。

Task context, robot state, token position and noise level each condition the network through a defined path.任务语境、本体状态、token 位置与噪声水平，通过各自明确的路径影响网络计算。
