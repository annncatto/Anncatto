02 · Model interface

Inputs, Targets and Outputs输入、训练目标与输出

Known at the start of a control window控制窗口开始时的已知信息

The robot provides a current multi-view observation $o_1$, a language instruction $\ell$, and its current proprioceptive state $q$. These describe the scene, the requested task and the robot configuration from which the next movement starts.机器人提供当前多视角观测 $o_1$、语言指令 $\ell$ 与本体状态 $q$，分别描述场景、任务目标和下一段运动开始时的机器人构型。

For example, “place the cup in the tray” requires locating both objects and knowing the current arm pose. The observed frame stays fixed while the model generates the next window.例如“把杯子放进托盘”需要同时确定物体位置与机械臂当前姿态。模型生成下一窗口时，当前观测帧始终作为固定条件。

Two coupled prediction targets两个耦合的预测目标

Training clips provide future visual latents $z$ and an action chunk $a_{1:H}$. The world branch learns the scene’s evolution; the action branch learns the commands associated with that evolution. $T$ counts video frames and $H$ counts action steps.训练片段提供未来视觉潜变量 $z$ 与动作块 $a_{1:H}$。世界分支学习场景怎样演化，动作分支学习与这些变化对应的控制指令；$T$ 是视频帧数，$H$ 是动作步数。

At inference, the future is unknown. Both future variables start from noise and are generated together; the final action chunk is mapped back to the robot’s command space.推理时未来信息未知。两类未来变量都从噪声出发共同生成，最终动作块再映射回机器人的指令空间。

The current observation is a condition; future video and future actions are jointly generated variables.当前观测是条件，未来视频与未来动作是共同生成的变量。
