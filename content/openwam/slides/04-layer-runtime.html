Infra supports dual-system joint self-attention, the configuration retained by Study and OpenWAM-α. Each stream owns its parameters and exchanges features inside paired Transformer layers.双系统联合自注意力是 Infra 支持、且 Study 后续研究与 OpenWAM-α 采用的配置。两流保留独立参数，在配对的 Transformer 层内交换特征。

One paired layer一对配对层的计算

  1. Project: each stream maps its tokens to its own Q/K/V.各自投影：两流分别把 token 映射为自己的 Q/K/V。
  2. Attend: concatenate along the token axis, apply masked attention, then split.联合注意力：沿 token 维度拼接，按掩码计算，再拆回两流。
  3. Continue: each stream applies its own output projection and FFN. α repeats this at all 30 paired layers.独立后半层：各流执行自己的输出投影与前馈网络。α 的 30 对层均重复这种交换。

Parameters and gradients参数与梯度

Joint attention shares intermediate features; projection and FFN parameters remain stream-specific. The visibility mask determines which features each query reads.联合注意力交换中间特征，投影与前馈网络的参数仍归各流所有；可见性掩码决定 Query 能读取哪些特征。

Action loss can update the video backbone through those features. Detachment blocks that gradient path; freezing prevents the corresponding parameter updates.动作损失可沿读取的视频特征更新视频骨干。分离梯度阻断该传播路径，冻结参数则阻止相应权重更新。
