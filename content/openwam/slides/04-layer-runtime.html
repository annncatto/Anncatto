“Joint network” denotes the configured WAM, not a single connection shared by every Infra architecture. The example below is a dual system with joint self-attention.“联合网络”泛指所配置的 WAM，不同 Infra 架构具有不同连接方式。下图仅以双系统联合自注意力为例。

Information exchange inside a layer层内的信息交换

  1. Video DiT and ActionDiT process their own tokens.Video DiT 与 ActionDiT 分别处理各自 token。
  2. Each stream produces its own Q, K and V.两流分别生成自己的 Q、K、V。
  3. Concatenate Q/K/V along the token dimension.将 Q/K/V 沿 token 维度拼接。
  4. Compute joint attention under the visibility mask.按可见性掩码计算联合注意力。
  5. Split outputs back and continue each stream’s network.结果拆回两流，继续各自网络计算。

Each stream retains its own parameters. The mask governs access to the other stream’s intermediate features. OpenWAM-α exchanges features at all 30 paired layers.两流保留各自参数，按掩码读取对方中间特征。OpenWAM-α 的 30 对层均参与这种交换。

Checkpoints and training continuity检查点与训练延续

  • Rebuild the model: save weights, complete module specifications and action-normalization statistics together. Fine-tuning and deployment restore the same architecture and action scale.重建模型：一并保存权重、完整模块配置和动作归一化统计量。微调与部署据此还原模型结构及动作尺度。
  • Resume a run: also restore Adam moments, learning-rate progress and data position. Normalization statistics must match the saved record.断点续训：还原优化器的历史统计量、学习率进度和数据读取位置，并校验归一化统计量与原记录一致。
  • Run training: Accelerate + ZeRO-1/2, BF16, gradient accumulation and clipping; activation checkpointing and optional CPU offload reduce memory use.训练运行：Accelerate＋ZeRO-1/2、BF16、梯度累积与裁剪；激活检查点和可选 CPU 卸载降低显存占用。
