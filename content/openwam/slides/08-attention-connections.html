Single layer and head: $H_r\in\mathbb R^{n_r\times d_r}$ contains $n_r$ tokens of stream $r\in\{v,a\}$. Separate projections produce Q/K/V with common head width $d$.以单层、单头表示：$H_r\in\mathbb R^{n_r\times d_r}$ 为流 $r\in\{v,a\}$ 的 $n_r$ 个 token；两流各自投影生成 Q/K/V，共同头维为 $d$。

Q: reader; K/V: sources. softmax normalizes each row. Additive mask: $M_{ij}=0$ allows access; $-\infty$ blocks it.Q 为读取者，K/V 为来源。softmax 按行归一化；加性掩码 $M_{ij}=0$ 表示可见，$-\infty$ 表示屏蔽。

Joint self-attention · One joint token pool联合自注意力 · 合并 token 序列

$$S=\frac{1}{\sqrt d}\begin{bmatrix}Q_vK_v^{\mathsf T}&Q_vK_a^{\mathsf T}\\Q_aK_v^{\mathsf T}&Q_aK_a^{\mathsf T}\end{bmatrix}+M$$
$$P=\operatorname{softmax}_{\rm row}(S),\qquad B_a=P_{av}V_v+P_{aa}V_a.$$

Rows are Query readers; columns are Key/Value sources. $Q_aK_v^{\mathsf T}$ scores action-to-video reads; $P_{av}\in\mathbb R^{n_a\times n_v}$ weights them.行对应 Query 读取者，列对应 Key/Value 来源。$Q_aK_v^{\mathsf T}$ 是动作读取视频的分数，$P_{av}\in\mathbb R^{n_a\times n_v}$ 为对应权重。

Each action row normalizes across visible video/action keys together. Outputs return to each stream. Its projection and FFN parameters stay independent.每个动作行在可见的视频／动作 Key 上共同归一化。输出拆回两流，各自投影与 FFN 参数保持独立。

Joint cross-attention · An extra video-to-action bridge联合交叉注意力 · 增加视频到动作的桥接

$$\begin{aligned}Q_a^c&=H_aW_{Q,a}^c,\\K_v^c&=H_vW_{K,v}^c,\qquad V_v^c=H_vW_{V,v}^c.\end{aligned}$$
$$C_a=\operatorname{softmax}_{\rm row}\!\left(d^{-1/2}Q_a^c(K_v^c)^{\mathsf T}+M_{av}\right)V_v^c.$$

Q comes from actions; K/V from video. This softmax uses video keys only. $\Delta H_a=C_aW_{O,a}^c$ updates actions; within-stream self-attention remains separate.Q 来自动作，K/V 来自视频；只在视频 Key上归一化。$\Delta H_a=C_aW_{O,a}^c$ 更新动作，流内自注意力另行计算。

Superscript $c$ marks this cross-attention module. Text/state cross-attention uses context features as K/V: the same operator with different sources.上标 $c$ 标记交叉注意力模块。语言／状态交叉注意力的 K/V 来自上下文：算子相同，特征来源不同。

Feature exchange and gradient propagation特征传递与梯度传播

$$\left.\frac{\partial\mathcal L_a}{\partial\theta_v}\right|_{\rm bridge}=\frac{\partial\mathcal L_a}{\partial C_a}\frac{\partial C_a}{\partial H_v}\frac{\partial H_v}{\partial\theta_v}\quad\xrightarrow{\ H_v\,\mapsto\,\operatorname{sg}(H_v)\ }\quad 0$$

Detachment: $\operatorname{sg}(H_v)=H_v$ forward; $\partial\operatorname{sg}(H_v)/\partial H_v=0$ backward. This blocks the action-loss path into $\theta_v$; video loss still trains these parameters.上式为一条桥接到视频参数 $\theta_v$ 的梯度路径。分离梯度保持 $\operatorname{sg}(H_v)=H_v$，但令 $\partial\operatorname{sg}(H_v)/\partial H_v=0$：前向传递特征，反向截断动作损失的梯度；视频损失仍训练视频参数。
