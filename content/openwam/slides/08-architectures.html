Model capacity is the ability to represent complex mappings. Study compares action-specific capacity through parameter allocation: attention mixes token features, while feed-forward networks (FFNs) transform each token nonlinearly.建模容量指网络表示复杂映射的能力。本组通过参数配置比较动作专属容量：注意力读取与汇总 token 特征，前馈网络（FFN）对每个 token 进行非线性变换。
