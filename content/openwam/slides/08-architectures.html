Model capacity is a network’s ability to represent complex mappings. Study asks how much of it should be dedicated to actions, comparing shared parameters, action-specific FFNs and independent action backbones.模型容量是网络表示复杂输入—输出映射的能力，受参数量与网络结构影响。本组研究动作专属建模容量：比较共享参数、动作专属 FFN 与独立动作骨干，并考察视频、动作两流应分离到何种程度。

Action-branch parameter allocation动作分支的参数配置

Vanilla shares attention and FFNs; MoE keeps shared attention but adds action-specific FFNs. Dual provides an independent ActionDiT; Tri adds a stream processing VLM features.Vanilla 共享注意力与 FFN；MoE 保持共享注意力，为动作设置专属 FFN。双系统提供独立 ActionDiT；三系统再增加处理 VLM 特征的理解流。

Attention and generation order注意力与生成顺序

Joint self-attention joins both token sequences at bridge layers. Cross-attention lets the action stream query video features.联合自注意力在桥接层合并两流 token；交叉注意力由动作流查询视频特征。

Detached cross-attention stops action gradients at video features. IDM first generates future video, then predicts actions conditioned on it.分离梯度交叉注意力阻断视频特征处的动作梯度。IDM（逆动力学）先生成未来视频，再以其为条件预测动作。
