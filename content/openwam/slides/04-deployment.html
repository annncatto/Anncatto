Serving Schedules and Evaluation执行调度与评测协议

Synchronous serving同步执行

Robot
Execute A执行 A
Wait等待
Execute B执行 B
Model
Infer B预测 B
  • An empty buffer pauses the robot until inference returns.缓冲耗尽后，机器人等待推理返回。
  • Execution and computation are serial.动作执行与模型计算串行进行。

Window n sets how long the robot executes before replanning; longer windows delay feedback updates.执行窗口 n 决定两次重规划之间执行多久；窗口越长，反馈更新间隔越长。

Asynchronous serving异步执行

Robot
Execute A执行 A
Execute B执行 B
Model
Infer B预测 B
  • Start prediction before the current buffer ends.当前缓冲结束前提前预测。
  • Skip the stale prefix and align the new chunk.跳过过时前缀，对齐新动作块。

H: prediction horizon; n: execution window; d = n/2: default lookahead.H：预测长度；n：执行窗口；默认提前量 d = n/2。
