06 · Cross-stream computation

Inside an Attention Bridge注意力桥接层内部

$$\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_h}}+M\right)V$$

Each token projects a query $Q$, key $K$ and value $V$. For each query, $QK^{\mathsf T}$ scores which source tokens are relevant. Softmax converts the permitted scores into weights, and their weighted sum of $V$ forms the new feature. An action token can therefore combine information from its own action sequence and the world stream.每个 token 投影得到查询 $Q$、键 $K$ 与值 $V$。$QK^{\mathsf T}$ 计算它与来源 token 的相关性，softmax 将允许读取的分数转为权重，再对 $V$ 中的信息加权求和。动作 token 由此能够同时整合自身动作序列与世界流中的信息。

The world and action streams first apply their own Q/K/V projections. In α, widths 3072 and 1024 are projected into a common attention space of 24 heads × 128 dimensions. Within each head, the two token sequences are concatenated to length $N_v+N_a$, with $N_a=H$.世界流与动作流先使用各自的 Q/K/V 投影。在 α 中，3072 与 1024 的残差宽度都映射到 24 头 × 128 维的共同注意力空间；每个头内沿 token 轴拼接，得到长度 $N_v+N_a$ 的序列，其中 $N_a=H$。

The mask $M$ selects readable pairs: 0 allows attention and $-\infty$ blocks it. After attention, outputs are split by token index and projected back to each stream’s residual width, then processed by its own residual and FFN paths. Shared attention therefore exchanges features while preserving separate backbone weights.掩码 $M$ 用 0 允许读取、用 $-\infty$ 屏蔽读取。注意力结果再按 token 位置拆回两流，分别投影回原残差宽度，进入各自的残差与前馈路径。因此，共同的注意力计算能交换特征，同时保留独立骨干参数。

“Shared attention” shares a computation space, while each stream retains its own projections and backbone.“共享注意力”共享计算空间；投影层与骨干参数仍由各流分别持有。
