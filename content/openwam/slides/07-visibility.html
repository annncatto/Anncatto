$O$ denotes observed-frame tokens, $V$ noisy future-world tokens, and $A$ noisy action tokens. $O$ reads only $O$, so the current observation is not contaminated by generated future information. Both $V$ and $A$ can always read $O$.$O$ 表示当前观测 token，$V$ 表示加噪的未来世界 token，$A$ 表示加噪动作 token。$O$ 只读取 $O$，保持当前观测不受生成中的未来信息影响；$V$ 与 $A$ 始终可以读取 $O$。

Future video tokens can read one another, as can all action positions within the chunk. “Isolated” removes only future-world/action exchange, while preserving current visual conditioning.未来视频 token 之间、动作块各位置之间均可相互读取。“隔离”仅关闭未来世界与动作之间的交换，仍保留当前视觉条件。

Direction follows the reader信息方向由读取者决定

When action queries read world keys, information flows $V\rightarrow A$: actions use the world stream’s evolving representations. The reverse block gives $A\rightarrow V$. Mutual attention enables both directions, as used in α.当动作 Query 读取世界 Key时，信息沿 $V\rightarrow A$ 流动，动作利用世界流正在形成的表征；反向区块对应 $A\rightarrow V$。α 的互通模式同时开放两条方向。
