01 · Research question

World Prediction Meets Action Generation世界预测与动作生成

Dynamics as a control prior从视觉动态到控制先验

Large video models learn how scenes change: objects move, contacts occur, and manipulation changes object states. A World–Action Model (WAM) couples this visual prediction with action generation, so the action network can use features that describe possible future changes.大规模视频模型学习物体运动、接触和操作引起的状态变化。世界—动作模型（WAM）把这种视觉预测与动作生成结合，使动作网络能够利用描述未来变化的特征。

Robot action supervision also updates the coupled system. This gives visual features a control-related learning signal: predicting an image and selecting an executable movement become connected objectives.机器人动作监督也会更新耦合后的系统，为视觉特征提供与控制有关的学习信号：预测画面与选择可执行的运动由此成为相互联系的目标。

A research system, then a model先建立研究系统，再形成模型

OpenWAM-Infra makes encoders, backbones and attention patterns interchangeable. OpenWAM-Study uses controlled comparisons to identify which combinations help action learning. OpenWAM-α scales the selected combination through joint human–robot pretraining.OpenWAM-Infra使编码器、网络骨干与注意力模式可以组合；OpenWAM-Study通过受控比较筛选有利于动作学习的设计；OpenWAM-α再用人类与机器人数据联合预训练这一组合。
