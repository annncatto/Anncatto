Three explicit design choices三个明确的设计维度

$E$, the visual encoder, defines what the world stream predicts. $S$, the stream backbones, assigns network capacity to world, action and optional understanding tokens. $M$, the visibility mask, determines which tokens can read which sources.视觉编码器 $E$定义世界流预测的表征；流骨干 $S$为世界、动作及可选的理解 token 分配网络容量；可见性掩码 $M$规定各 token 能够读取哪些信息。

A stream is a token-processing route; a backbone owns parameters. Two streams may share a backbone or keep separate networks. This distinction makes parameter sharing and information exchange independently configurable.“流”是一条 token 处理路径，“骨干”则持有网络参数。两条流可以共用骨干，也可以使用独立网络，因此参数共享与信息交换能够分别配置。

A common execution contract统一的执行接口

The composition $C$ owns no model parameters. It calls each backbone’s prepare → layer steps → finalize interface. At a bridge layer, the backbone exposes Q/K/V before attention and consumes its own attention output afterward.组合器 $C$ 本身不持有模型参数，通过各骨干统一的 prepare → 逐层计算 → finalize 接口组织前向过程。桥接层在注意力前提供 Q/K/V，在注意力后接回属于本流的结果。
