Visual Latents and Tokens视觉潜变量与 token

A compact, ordered prediction target紧凑且保留时序的预测目标

The frozen Wan2.2 causal variational autoencoder (VAE) encodes the first frame separately, then compresses subsequent frames in groups of four. A $T$-frame clip becomes $T'=1+(T-1)/4$ latent frames. Learned temporal compression retains information about changes within each group.冻结的 Wan2.2 因果变分自编码器（VAE）单独编码首帧，再以每四帧一组压缩后续视频。$T$ 帧片段得到 $T'=1+(T-1)/4$ 个潜变量帧；学习式时序压缩能够保留组内变化的信息。

The encoder defines the target’s coordinates. A matched pretrained video DiT brings a prior for generating in that latent space; changing the encoder can require adapting or retraining the generator.编码器决定预测目标的坐标空间。配套的预训练视频 DiT 已有在该空间中生成的先验；更换编码器后，生成器可能需要适配或重新训练。

Three sizes with different roles三种尺寸对应不同含义

Latent channels $C$ describe each encoded location. Token count $N_v$ follows from the latent grid and patch size. Hidden width $D_v$ is the Transformer feature size. In α, $(1,2,2)$ patches become 3072-D world tokens, with 3D RoPE locating frame, height and width.潜变量通道数 $C$描述每个编码位置；token 数 $N_v$取决于潜变量网格与 patch 大小；隐藏宽度 $D_v$是 Transformer 内部特征维度。α 将 $(1,2,2)$ patch 映射为 3072 维世界 token，并用 3D RoPE 标记帧、高度与宽度位置。

The visual encoder determines the world-prediction task and which pretrained generation prior can be reused.视觉编码器同时决定世界预测任务，以及能够继承哪一种预训练生成先验。
