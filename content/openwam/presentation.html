4 · OpenWAM-Study / Summary

Design PrinciplesDesign Principles

Inherit继承

  • Use a pretrained video generator.使用预训练视频生成器。
  • Keep a compact, temporally structured prediction space.保留紧凑、具有时序结构的预测空间。

Couple协同

  • Allocate separate video and action capacity.为视频与动作分配独立容量。
  • Let actions read world features.让动作读取世界特征。
  • Use synchronous denoising in the tested setting.在被测设置中采用同步去噪。

Transfer迁移

  • Mix robot trajectories and human video.混合机器人轨迹与人类视频。
  • Use mutual visibility for the pretrained model.预训练模型采用双向可见。
  • Evaluate ID and OOD separately.分别评估 ID 与 OOD。
OpenWAM-α composes these experimentally supported choices into a pretrained model.OpenWAM-α 将这些受实验支持的选择组合成预训练模型。

5 · OpenWAM-α / Architecture

Layer-Wise Attention BridgesLayer-Wise Attention Bridges

The video stream uses width 3072; the action stream uses width 1024. Projections align their queries, keys and values to 24 attention heads of width 128.视频流宽度为 3072，动作流宽度为 1024；投影将它们的 Query、Key、Value 对齐到 24 个、每个 128 维的注意力头。

Video tokens use 3D RoPE and action tokens use 1D RoPE. Shared attention exchanges information while modality-specific layers preserve separate parameters.视频 token 采用 3D RoPE，动作 token 采用 1D RoPE；共享注意力交换信息，各模态的专用层保留独立参数。

World priors世界先验
