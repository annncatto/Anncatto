Admission before actuation写入前准入

Validate robot model, session, control epoch, command sequence and finite target ranges.校验型号、会话、控制权代次、命令序号，以及有限值与目标范围。

Robot-side protection机器人端保护

Current/feedback supervision and a 2 s no-valid-write watchdog run in Host.电流与反馈监督、2 s 无有效写入看门狗在 Host 运行。

Explicit action semantics显式动作语义

Calibrated joint coordinates; base m/s and °/s; lift mm. Network submission and hardware feedback are recorded separately.关节使用标定坐标；底盘为 m/s、°/s；升降为 mm。分别记录通信提交与硬件反馈。

One runtime serves teleoperation, learned policies and ROS2, so command ownership and protection remain consistent across applications.遥操作、学习策略和 ROS2 共用运行时，使控制权限、动作解释与保护规则在不同应用中保持一致。
