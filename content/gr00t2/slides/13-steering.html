Language can leave the target object, destination or acting arm ambiguous. The WAM API therefore lets an agent add image-space grasp/release points to the instruction; GR00T 2 generates the intervening manipulation.语言可能无法明确指代目标物体、目的地或执行手臂。WAM API 因此允许智能体在指令之外加入图像空间的抓取／释放点，由 GR00T 2 生成中间操作动作。

Mid-training uses point labels extracted automatically from gripper/hand states in existing demonstrations. Compared with task instructions alone and agent language guidance, adding visual markers raises short-horizon benchmark means 35.7→44.2→76.8% and long-horizon means 0→1.7→53.3%. These are equal-weight benchmark means.中间训练使用从已有示范的夹爪／手部状态自动提取的点标记。依次比较任务指令、智能体语言引导、语言加视觉标记，短时序基准均值为 35.7→44.2→76.8%，长时序为 0→1.7→53.3%；均为各基准等权平均。

Markers specify spatial targets; orientation, pouring, scooping and other motion requirements still depend on language and learned skills.点标记提供空间目标；物体朝向、倾倒、舀取等动作要求仍依赖语言和已学技能。
