Visual representation视觉表示

Frozen Wan 2.1 VAE: 4× temporal and 8× spatial compression per axis. At 224×320, patches yield 280 tokens per latent frame and camera.冻结 Wan 2.1 VAE：时间压缩 4 倍，空间每轴压缩 8 倍。224×320 图像经潜变量分块后，每相机每潜帧得到 280 个 token。

Shared backbone共享骨干

Initialized from Cosmos-Predict2.5-2B. Video, state and action tokens enter one 2B Transformer; text features enter cross-attention.由 Cosmos-Predict2.5-2B 初始化。视频、状态、动作 token 进入同一个 2B Transformer；文本特征通过交叉注意力提供条件。

Embodiment interface本体接口

Small robot-specific MLPs encode states and actions and decode action tokens into each robot’s coordinates.小型本体专属 MLP 编码状态与动作，再把动作 token 解码到对应机器人的动作坐标。
