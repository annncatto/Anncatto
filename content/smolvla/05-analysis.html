双玩偶实验Two-toy experiment

在单玩偶任务基础上，增加 120 条双玩偶示教，覆盖三种相对布局与位置变化。

The extension adds 120 two-toy demonstrations with three relative layouts and placement variations.

{{svmedia:two-toys-a|two-toys-b}}

补充训练后，单玩偶与双玩偶测试均出现失败。双玩偶收集包括目标选择、依次抓取和完成判定；第一件物体移除后，视觉条件与后续动作阶段随之改变。

Both single- and two-toy tests show failures after the extension. Two-toy collection involves target selection, sequential grasps, and termination. Removing the first object changes visual conditions and subsequent action phases.

当同一观察条件支持不同抓取顺序时，条件动作分布 $p(A\mid o)$ 具有多模态结构。流匹配负责生成连续动作，目标标识与阶段条件则负责区分动作意图。第二次接近、抓取后重观察和收集结束状态构成长程任务的关键转移。

Different valid grasp orders under the same observation create a multimodal conditional distribution $p(A\mid o)$. Flow matching generates continuous actions; target and phase conditioning disambiguate intent. Second approaches, re-observation after grasping, and collection termination form key long-horizon transitions.

实验变化集中在三类因素：归一化统计改变数值坐标，初始布局与目标数量改变条件分布，重规划周期与推理延迟改变闭环修正频率。对照实验分别固定其他条件，比较每类因素对旧任务保持、新条件适应和动作连续性的影响。

Three groups of changes dominate the experiments: normalization changes numerical coordinates; initial layout and object count change conditioning distributions; replanning and latency change closed-loop correction frequency. Controlled comparisons isolate their effects on retention, adaptation, and continuity.

后续实验Further experiments

  • 测试分组：固定复位姿态、控制频率和结束条件，分别测试原位置、距离变化、横向位置变化和双玩偶布局；记录各组成功次数、总次数、完成时间与人工干预。
  • 能力保持：以 120 条检查点为起点，分别对照统计量、旧新数据采样比例和继续训练时长；按接近、夹持、抬起、投放四个阶段统计失败位置。
  • 执行时序：记录观察采样、推理起止、chunk 返回和每步执行时间；结合队列长度与原始动作，量化计算等待、动作过时和块间跳变。
  • 双目标覆盖：分别评估第一次抓取、第二次接近和任务结束；将移除首个玩偶后的重观察、恢复动作与第二次抓取纳入示教。
  • Evaluation groups: fix reset, control rate, and termination; test original, distance-shifted, lateral-shifted, and two-toy layouts. Record successes, attempts, completion time, and interventions.
  • Retention: start from the 120-episode checkpoint and separately compare statistics, old/new sampling ratios, and continuation duration. Score approach, grasp, lift, and deposit failures.
  • Execution timing: log observation, inference, chunk return, and command timestamps. Queue lengths and raw actions quantify waiting, stale actions, and boundary jumps.
  • Two-target coverage: evaluate first grasp, second approach, and termination separately. Include re-observation after removing the first toy, recovery, and second-grasp demonstrations.

120 条示教建立了 SmolVLA 的任务基线；150 条继续训练记录暴露出抓取稳定性下降与后退过量；π0.5 在相同任务中完成收集，动作阶段间停顿减少。双玩偶扩展进一步引入目标选择与阶段转移问题。后续实验围绕这些具体行为组织数据与控制变量。

The 120-demonstration run establishes the SmolVLA baseline. Continued training on 150 exposes reduced grasp consistency and excessive retreat. π0.5 completes collection with fewer inter-phase pauses. Two-toy expansion introduces target-selection and phase-transition issues. Further experiments organize data and controls around these behaviors.
