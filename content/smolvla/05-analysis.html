Implications and evidence boundaries实验启发与证据边界

  1. Keep trainable weights and AdamW moments in FP32可训练权重与 AdamW 矩估计保持 FP32

    Configure and log trainable parameter storage separately from BF16 autocast compute so low-lr decay updates keep moving the 96.6M expert body instead of redirecting updates into 26 FP32 tensors.

    将可训练参数与矩估计的存储精度与 BF16 autocast 计算精度分开配置与登记，确保衰减期小更新继续推动 96.6M 专家主体，而不被挤向 26 个 FP32 张量。

  2. Rebalance boundary-skewed data and add an std floor to near-constant states补采抬升/恢复示范并为近常量状态设置标准差下限

    In the 150 demos, 54% of shoulder_lift labels sit below −95 and 89% of right-gripper labels below 5. Add lift, missed-grasp reopen, and recovery demos with right-wrist coverage, and apply a minimum std floor on near-constant channels such as the left gripper (std 0.22) so initial offsets never trigger 49σ L01 anchor collapse.

    150 条数据中 54% 的 shoulder_lift 标签低于 −95、89% 的右夹爪标签低于 5。应补采抬升、漏抓重开与恢复示范（含右腕视角），并对近常量左夹爪（std 0.22）设置标准差下限，避免起步微差放大为 49σ 并打断 L01 状态锚点。

  3. Smooth chunk handoffs and score execution metrics separately在块交接引入重叠聚合/RTC 并拆分真机计分

    Replace hard 25-step chunk switching with overlap aggregation or RTC prefix conditioning, and log raw chunks, command IDs, output bounds, handoff jumps, and stage-level success independently.

    用重叠动作聚合或 RTC 前缀条件替代 25 步同步硬切块，并将离线拟合、输出合法性、交接跳变与分阶段真机成功率拆开计分，同时落盘原始动作块与命令 ID。

  4. Apply MiTA compression + routing when prefix length scales into the thousands当高分辨或多帧历史把前缀推至数千 token 时引入 MiTA

    When relaxing pixel shuffle for higher-resolution wrist_right patches or adding $T=4\text{–}16$ history frames pushes $P$ into the thousands against the $gH/f\gtrsim\ell$ latency budget, adopt temporal action landmarks ($m\ge4$) paired with routed raw K/V. Avoid concatenating raw state keys directly into Agent’s landmark query space (which raised loss +16%); stabilize state normalization instead.

    当取消 pixel shuffle（保留高分辨率右腕 patch）或引入 $T=4\text{–}16$ 帧历史观测使 $P$ 升至数千、逼近 $gH/f\gtrsim\ell$ 延迟上限时，适合采用“时序地标压缩（$m\ge4$）+ Top-$k$ 路由”。跨模态改造中不把原始 state key 直接硬拼进地标 query 空间（实测反而升 loss 16%），而通过标准差下限保持状态锚点稳定。

Current evidence boundaries: Measured facts cover 5k–120k matched replay, four-group and layerwise L2 weight splits, 32 single-layer swaps, 90-window boundary crossings, the 300 s FP32 live trace, 117 observation substitutions, and zero-retraining odd-CA sweeps/routing. Scope boundaries and open confounds: (1) Mixed 100k and FP32 100k varied storage precision and BF16 autocast compute together; (2) the 150-demo stage has zero held-out validation episodes, so offline replays measure training-window absorption rather than out-of-distribution generalization; (3) the 300 s live run is a single continuous rollout without matched Mixed-vs-FP32 paired resets or raw chunk-ID logs, and clamping the 14 zero-padded Euler dimensions has not been ablated yet; (4) MiTA probes verify representational compressibility on $P=305$, whereas wall-clock speedup requires long-prefix configurations ($P\gg 305$). Each deferred variable is isolated in the controlled plan below.

当前证据边界：已测事实包括 5k–120k 配对回放、四类与逐层相对 L2 变化、32 次单层替换、90 窗口贴边越界、300 s FP32 真机实录、117 次观测替换及免重训奇数 CA 预算扫描与白盒路由。适用边界与待解耦项：① 混合 100k 与 FP32 100k 同时改变了参数/矩估计存储精度与 BF16 autocast 计算精度；② 150 条阶段无独立验证集，离线回放衡量的是训练窗口拟合深度而非留出泛化；③ 300 s 真机记录为单次连续实录，未配对测试混合对 FP32 或落盘原始块 ID，14 个补零维在 Euler 积分中的置零消融尚未实测；④ 当前 $P=305$ 的单帧前缀上改用 MiTA 并无实际延迟收益，壁钟提速需在多帧或高分辨长前缀上检验。上述待验证假设统一交由下方受控实验逐项拆解。
