Model architecture模型架构

SmolVLA combines a pretrained SmolVLM2 backbone with an approximately 100M-parameter action expert. The released weights contain about 450M parameters in total.

SmolVLA 将预训练的 SmolVLM2 骨干与约 100M 参数的动作专家组合起来。发布权重总计约 450M 参数。

Camera images, a language instruction and robot state condition an action chunk $A=[a_0,\ldots,a_{H-1}]\in\mathbb R^{H\times D}$. The horizon $H$ covers future control steps; $D$ is the action width and $B$ denotes batch size.

模型根据相机图像、语言指令和机器人状态生成动作块 $A=[a_0,\ldots,a_{H-1}]\in\mathbb R^{H\times D}$。$H$ 表示未来控制步数，$D$ 为动作维度，$B$ 为 batch size。

The release configuration predicts 50 actions with an internal state/action width of 32. This robot uses 18 real dimensions, padded to $[B,50,32]$ during modeling and cropped before action restoration.

发布配置预测 50 步动作，状态与动作的内部维度均为 32。本机器人使用 18 个真实维度，建模时补零至 $[B,50,32]$，动作还原前裁去补零维。

Feature encoding特征编码

SmolVLM2 compresses visual patches with pixel shuffle, then projects them into a 960-dimensional language space. At $512\times512$ resolution, $16\times16$ patches yield 1,024 features; fourfold compression along each spatial axis leaves 64 visual tokens.

SmolVLM2通过 pixel shuffle 压缩视觉 patch，再投影到 960 维语言空间。$512\times512$ 图像按 $16\times16$ 分块得到 1,024 个特征，空间两轴各压缩 4 倍后留下 64 个视觉 token。

{{smolvla:features}}

Visual tokens, embedded language IDs and one projected state token form the observation prefix. Four 64-token views, 48 text positions and one state token give $P=305$ and shape $[B,305,960]$; padding masks mark unused text positions.

视觉 token、语言 embedding 与一个投影后的状态 token 组成观测前缀。四路图像各 64 个 token，加上 48 个文本位置和一个状态 token，得到 $P=305$、形状为 $[B,305,960]$ 的前缀；padding mask 标记未使用的文本位置。

The policy retains 16 VLM text layers and pairs them with a 16-layer expert of width $960\times0.75=720$. Each expert layer receives the matching VLM layer’s keys and values: five 64-wide KV heads, stored as $[B,5,P,64]$.

策略保留 VLM 的前 16 层，并配套一个 16 层、宽度为 $960\times0.75=720$ 的动作专家。专家各层读取对应 VLM 层的 K/V：共 5 个、每个宽 64 的 KV head，实现中的缓存形状为 $[B,5,P,64]$。

The prefix mask lets image and text tokens interact, while the state token reads the preceding visual-language context. Action queries access this prefix and the action positions permitted by the expert mask.

前缀掩码允许图像与文本 token 交互，状态 token 读取前面的视觉语言上下文。动作 Query 则读取前缀，以及专家掩码允许访问的动作位置。

Attention mechanism注意力机制

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.$$

Cross-attention (CA) brings observation features into the action expert. Self-attention (SA) connects action positions within a chunk, allowing their predictions to coordinate.

交叉注意力（CA）将观测特征引入动作专家。自注意力（SA）连接动作块内的位置，使各步预测相互协调。

  • SA, even layers: action queries read prefix keys and causally permitted action keys.
  • CA, odd layers: action queries read prefix keys only.
  • Layer numbers are zero-based. The mask controls visibility while all noisy action positions are processed in parallel. Layer implementation.
  • SA，偶数层：动作 Query 读取前缀 K/V，以及因果掩码允许的动作 K/V。
  • CA，奇数层：动作 Query 只读取前缀 K/V。
  • 层号从 0 开始；掩码控制可见性，全部加噪动作位置仍并行计算。分层实现。

The LIBERO ablation freezes the VLM and trains a new expert with CA-only, causal SA-only or alternating CA+SA. It tests whether observation conditioning and action-sequence dependencies contribute complementary information. SmolVLA §3.1.

LIBERO 消融冻结 VLM，从头训练动作专家，比较 CA-only、因果 SA-only 和交替 CA+SA。实验检验观测条件与动作序列依赖是否提供互补信息。SmolVLA §3.1。

Flow-matching training流匹配训练

Flow matching trains the expert to predict a velocity field between demonstrated actions and Gaussian noise. For each normalized action chunk $A$ and observation $o$, sample a flow time $t$ and noise $\epsilon$; this implementation places data at $t=0$ and noise at $t=1$.

流匹配训练让动作专家学习示范动作与高斯噪声之间的速度场。每个标准化动作块 $A$ 和观测 $o$ 配合随机时间 $t$、噪声 $\epsilon$ 构造训练样本；本实现将数据端设为 $t=0$，噪声端设为 $t=1$。

$$\epsilon\sim\mathcal N(0,I),\qquad x_t=(1-t)A+t\epsilon,\qquad u_t=\frac{\partial x_t}{\partial t}=\epsilon-A.$$
$$\mathcal L(\theta)=\mathbb E_{A,o,t,\epsilon}\left[\left\|v_\theta(x_t,t,o)-(\epsilon-A)\right\|_2^2\right].$$
{{smolvla:batch}}
  • Read $B$ examples: images $[B,N,3,h,w]$, text $[B,L]$, state $[B,D_s]$, and future actions $[B,H,D]$. Normalize and pad state/action dimensions.
  • Sample one time per example and matching Gaussian noise. Construct $x_t$ and target $u_t$.
  • Build the prefix; fuse noisy-action and time embeddings through an MLP into a $[B,H,720]$ suffix.
  • Run one expert forward pass and calculate elementwise MSE. The trainer reduces dimensions and masks, backpropagates, and updates trainable parameters.
  • 读取 $B$ 个样本：图像 $[B,N,3,h,w]$、文字 $[B,L]$、状态 $[B,D_s]$ 与未来动作 $[B,H,D]$。归一化后再补齐动作与状态维度。
  • 为每个样本抽取 $t\in\mathbb R^B$ 与 $\epsilon\in\mathbb R^{B\times H\times D}$，构造 noisy actions $x_t$ 和目标 $u_t$。
  • 图像、文字、状态生成 prefix；$x_t$ 与时间 embedding 经 MLP 融合为 $[B,H,720]$ 的 suffix。
  • 动作专家一次前向输出 $v_\theta$，与 $u_t$ 计算逐元素 MSE；训练器再按动作维度、padding mask 和 batch 聚合损失，反向传播并更新可训练参数。

Each training forward pass evaluates the field at one sampled flow time. Gradients update only the selected trainable parameters; inference instead repeatedly evaluates the learned field to generate actions.

一次训练前向在一个抽样的流时间上计算速度场。梯度只更新选定的可训练参数；推理则反复调用学到的速度场，逐步生成动作。

Action sampling动作采样

At inference, the policy builds the observation prefix and caches its layerwise keys and values. Starting from $x_1\sim\mathcal N(0,I)$, it integrates the generative ODE toward $t=0$ using $K$ Euler steps:

推理先构建观测前缀并缓存各层 K/V，再从 $x_1\sim\mathcal N(0,I)$ 出发，用 $K$ 次 Euler 更新将生成 ODE积分到 $t=0$：

$$t_k=1-\frac{k}{K},\qquad \Delta t=-\frac1K,\qquad x_{t_{k+1}}=x_{t_k}+\Delta t\,v_\theta(x_{t_k},t_k,o).$$
{{smolvla:sampling}}

The default $K=10$ requires ten expert evaluations with the same observation cache. The horizon $H=50$ sets prediction length, executed actions $n$ set the replanning interval, and frequency $f$ sets control timing. Field mapping and output limits follow cropping and restoration.

默认 $K=10$，即复用同一观测缓存、调用动作专家 10 次。预测时域 $H=50$ 决定输出长度，执行步数 $n$ 决定重规划间隔，频率 $f$ 决定控制节拍；裁维与反归一化后，再进行字段映射和限幅。

Asynchronous inference异步推理

Asynchronous inference requests a new chunk while the robot still executes queued actions. Overlapping prediction and execution reduces waits at queue exhaustion and permits earlier responses to changing observations. SmolVLA §3.3.

异步推理在机器人仍执行队列动作时请求下一个动作块。预测与执行重叠，可减少队列耗尽后的等待，并更早响应观测变化。SmolVLA §3.3。

For control frequency $f$, horizon $H$ and remaining-queue fraction $g$, the request-time buffer is $gH/f$. End-to-end latency $\ell$ consumes $d=\lceil f\ell\rceil$ control steps:

设控制频率为 $f$、预测时域为 $H$、剩余队列比例为 $g$，则请求时的缓冲时长为 $gH/f$。端到端延迟 $\ell$ 对应 $d=\lceil f\ell\rceil$ 个已经过去的控制步：

$$T_{\mathrm{buffer}}=\frac{gH}{f}\ \gtrsim\ \ell,\qquad d=\lceil f\ell\rceil,\qquad gH\gtrsim d.$$
{{smolvla:latency}}

Latency includes acquisition, encoding, transfer, queuing, preprocessing, sampling and return transfer. The queue skips stale leading actions in the new chunk and aggregates overlapping timesteps; joint-space filtering suppresses near-duplicate observation requests. Queue protocol.

延迟包含采集、编码、传输、排队、预处理、动作采样和返回传输。队列跳过新块中已经过时的前段动作，并聚合重叠时间位置；关节空间过滤则减少近似重复的观测请求。队列协议。

In the paper’s Pick-Place timing test, ten trials across five positions average 13.75 s synchronously and 9.70 s asynchronously. Fixed-time successful transfers rise from 9 to 19, while mean success across three tasks is 78.3% and 73.3%, respectively. SmolVLA §4.6.

论文的 Pick-Place 计时测试覆盖 5 个位置、10 次试验，同步与异步平均耗时分别为 13.75 s、9.70 s。固定时长内成功搬运数从 9 增至 19；三项任务的平均成功率则分别为 78.3%、73.3%。SmolVLA §4.6。

Real-Time Chunking (RTC) conditions the next prediction on the soon-to-execute prefix of the old chunk. This constraint addresses continuity at the replanning handoff.

Real-Time Chunking（RTC）把旧块中即将执行的动作前缀作为新预测的条件。这项约束用于处理重规划交接处的连续性。

Queue exhaustion, discontinuities between chunks and holds within a predicted chunk occur at different execution stages. Raw chunks, command IDs and timestamps distinguish them. RTC analysis.

队列耗尽、动作块之间跳变，以及预测块内部停顿，发生在不同执行阶段。原始动作块、命令 ID 与时间戳用于区分这些现象。RTC 执行分析。
