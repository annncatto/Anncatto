模型架构Model architecture

SmolVLA 由预训练的 SmolVLM2 主干与约 100M 参数的动作专家组成，完整发布模型约为 450M 参数。

SmolVLA combines a pretrained SmolVLM2 backbone with an action expert of approximately 100M parameters. The released model contains approximately 450M parameters in total.

模型接收多路相机图像、语言指令与机器人状态，输出动作块 $A=[a_0,\ldots,a_{H-1}]\in\mathbb R^{H\times D}$。$H$ 为预测时域，$D$ 为单步动作维度；训练批量 $B$ 表示同时处理的样本数。输入图像对应当前观察时刻，监督动作覆盖后续 $H$ 个控制步。

The model receives camera views, a language instruction, and robot state, then outputs an action chunk $A=[a_0,\ldots,a_{H-1}]\in\mathbb R^{H\times D}$. Here $H$ is the prediction horizon, $D$ the action dimension, and $B$ the training batch size. Images represent the current observation; supervision covers the following $H$ control steps.

发布配置的动作块长度为 50，状态与动作的最大维度均为 32。本实验使用 18 维控制向量，经补零形成模型内部的 $[B,50,32]$ 张量；输出阶段恢复 18 维动作并反归一化。相机顺序、字段顺序和统计量由策略的输入输出处理器统一管理。SmolVLA 配置。

The release configuration uses a 50-step horizon and maximum state/action width of 32. This experiment’s 18-dimensional controls are zero-padded to an internal $[B,50,32]$ tensor, then cropped and unnormalized at output. Policy processors define camera order, field order, and normalization statistics. SmolVLA configuration.

特征编码Feature encoding

SmolVLM2-500M 通过视觉编码器提取 patch 特征，使用 pixel shuffle 将相邻空间特征重排到通道维度，再投影至 960 维语言表示空间。对于 $512\times512$ 图像和 $16\times16$ patch，视觉编码产生 $32\times32=1024$ 个 patch 特征；两条空间轴各压缩 4 倍后，得到 $8\times8=64$ 个视觉 token。SmolVLM2 配置。

SmolVLM2-500M extracts patch features, rearranges neighboring spatial features into channels through pixel shuffle, and projects them into a 960-dimensional language space. A $512\times512$ image with $16\times16$ patches produces 1024 patch features. Fourfold compression along each spatial axis reduces these to $8\times8=64$ visual tokens. SmolVLM2 configuration.

{{smolvla:features}}

语言指令经分词与 embedding 转换为文本 token，连续状态经线性投影形成一个 state token。视觉、文本和状态 token 拼接为 prefix。四路相机各提供 64 个 token，文本分配 48 个位置，状态占一个位置，对应 $P=4\times64+48+1=305$，prefix 形状为 $[B,305,960]$。文本填充位置由 padding mask 屏蔽。

Language IDs are embedded, while continuous state is linearly projected into one state token. Visual, text, and state tokens form the prefix. Four views with 64 tokens each, 48 text positions, and one state token yield $P=305$ and shape $[B,305,960]$. Padding masks exclude unused text positions.

SmolVLA 保留 SmolVLM2 文本模型前 16 层，并配置 16 层动作专家，专家隐藏宽度为 $960\times0.75=720$。各层 VLM 的 key/value 为对应动作专家层提供条件信息。以 5 个 KV heads、每个 head 64 维计，缓存的逻辑形状为 $[B,P,5,64]$，实现中的存储布局为 $[B,5,P,64]$。

SmolVLA retains the first 16 text-model layers and uses a 16-layer action expert with hidden width $960\times0.75=720$. Layer-aligned VLM keys and values condition the expert. Five KV heads of width 64 give logical cache shape $[B,P,5,64]$, stored as $[B,5,P,64]$ in the implementation.

prefix 采用分块可见性约束：图像与语言 token 在前缀内交互，state token 可读取前面的视觉语言信息；动作 token 读取 prefix，并按专家层的注意力结构交换动作信息。状态投影层将连续关节状态接入这一条件通路。Prefix 与 suffix 实现。

Blockwise visibility governs the prefix: image and text tokens interact within their prefix block, state reads preceding visual-language tokens, and action tokens read the prefix and exchange action information according to the expert layer. The state projector supplies continuous joint information to this conditioning path. Prefix and suffix implementation.

注意力机制Attention mechanism

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.$$

注意力通过 query、key 与 value 建立条件依赖。交叉注意力（CA）的 query 来自动作表示，key/value 来自 VLM 特征，用于引入视觉、语言和状态条件；自注意力（SA）建立动作位置之间的依赖，用于协调同一动作块中的接近、夹持与抬起等连续控制。

Attention represents conditional dependencies through queries, keys, and values. Cross-attention uses action queries with VLM keys/values to supply visual, language, and state conditioning. Self-attention couples action positions, coordinating controls within a chunk.

专家层从 0 编号：偶数层采用 SA，奇数层采用 CA。SA 层的动作 query 读取 prefix KV 与因果 mask 允许的动作位置；CA 层读取 prefix KV。因果 mask 约束动作间的信息依赖，整个 noisy action chunk 在每次前向中并行计算。注意力实现。

With zero-based indexing, even expert layers use SA and odd layers use CA. SA action queries read prefix KV and causally permitted action positions; CA reads prefix KV. The causal mask constrains information access while the entire noisy chunk is processed in parallel. Attention implementation.

流匹配训练Flow-matching training

流匹配训练以当前观察 $o$ 和未来示范动作 $A$ 为监督样本。每个样本独立抽取流时间 $t$ 与高斯噪声 $\epsilon$，构造示范与噪声之间的插值，并监督该位置的向量场。采用实现中的 noise-at-one 约定：$t=0$ 对应示范动作，$t=1$ 对应高斯噪声。

Flow-matching training uses observation $o$ and demonstrated future actions $A$. Each example samples flow time $t$ and Gaussian noise $\epsilon$, constructs their interpolation, and supervises the vector field there. The implementation uses data at $t=0$ and noise at $t=1$.

$$\epsilon\sim\mathcal N(0,I),\qquad x_t=(1-t)A+t\epsilon,\qquad u_t=\frac{\partial x_t}{\partial t}=\epsilon-A.$$
$$\mathcal L(\theta)=\mathbb E_{A,o,t,\epsilon}\left[\left\|v_\theta(x_t,t,o)-(\epsilon-A)\right\|_2^2\right].$$
{{smolvla:batch}}
  • 读取 $B$ 个样本：图像 $[B,N,3,h,w]$、文字 $[B,L]$、状态 $[B,D_s]$ 与未来动作 $[B,H,D]$。归一化后再补齐动作与状态维度。
  • 为每个样本抽取 $t\in\mathbb R^B$ 与 $\epsilon\in\mathbb R^{B\times H\times D}$，构造 noisy actions $x_t$ 和目标 $u_t$。
  • 图像、文字、状态生成 prefix；$x_t$ 与时间 embedding 经 MLP 融合为 $[B,H,720]$ 的 suffix。
  • 动作专家一次前向输出 $v_\theta$，与 $u_t$ 计算逐元素 MSE；训练器再按动作维度、padding mask 和 batch 聚合损失，反向传播并更新可训练参数。
  • Read $B$ examples: images $[B,N,3,h,w]$, text $[B,L]$, state $[B,D_s]$, and future actions $[B,H,D]$. Normalize and pad state/action dimensions.
  • Sample one time per example and matching Gaussian noise. Construct $x_t$ and target $u_t$.
  • Build the prefix; fuse noisy-action and time embeddings through an MLP into a $[B,H,720]$ suffix.
  • Run one expert forward pass and calculate elementwise MSE. The trainer reduces dimensions and masks, backpropagates, and updates trainable parameters.

一次训练前向在随机流时间计算向量场损失；动作采样阶段通过多次向量场求值完成积分。训练中的梯度沿 prefix 与动作专家通路传播，参数更新范围由 requires_grad 和优化器参数组确定。

A training forward evaluates vector-field loss at a sampled flow time. Action sampling instead integrates through repeated field evaluations. Training gradients propagate through prefix and expert operations; requires_grad settings and optimizer groups determine which parameters update.

动作采样Action sampling

动作采样首先计算当前观察的 prefix 和各层 KV 缓存，再以 $x_1\sim\mathcal N(0,I)$ 初始化动作块，通过 $K$ 步 Euler 积分求解生成过程的常微分方程：

Action sampling computes the observation prefix and layerwise KV cache, initializes $x_1\sim\mathcal N(0,I)$, and solves the generative ODE with $K$ Euler steps:

$$t_k=1-\frac{k}{K},\qquad \Delta t=-\frac1K,\qquad x_{t_{k+1}}=x_{t_k}+\Delta t\,v_\theta(x_{t_k},t_k,o).$$
{{smolvla:sampling}}

默认配置使用 $K=10$ 次专家求值，观察 prefix 在这次采样内复用。预测时域 $H=50$ 决定输出长度，执行步数 $n$ 决定两次重规划之间消耗的动作数，控制频率 $f$ 决定每个动作的时间间隔。最终动作经过截维、反归一化、字段映射与限幅后发送至机器人。

The default uses $K=10$ expert evaluations while reusing the observation prefix. Horizon $H=50$ determines output length, executed steps $n$ determine the interval between replans, and control frequency $f$ sets the action period. Cropping, restoration, field mapping, and limiting precede transmission.

异步推理Asynchronous inference

同步执行在动作块结束后等待新预测。异步执行在旧队列尚有剩余动作时发送观察，使预测计算与动作执行重叠。设控制频率为 $f$、动作块长度为 $H$、触发阈值为剩余比例 $g$，则触发时的缓冲时间为 $gH/f$。端到端延迟 $\ell$ 对应的动作步数为 $d=\lceil f\ell\rceil$：

Synchronous execution waits for a new prediction after a chunk ends. Asynchronous execution requests a prediction while actions remain, overlapping computation and execution. With frequency $f$, horizon $H$, and remaining-fraction threshold $g$, the buffer is $gH/f$. End-to-end latency $\ell$ corresponds to $d=\lceil f\ell\rceil$ action steps:

$$T_{\mathrm{buffer}}=\frac{gH}{f}\ \gtrsim\ \ell,\qquad d=\lceil f\ell\rceil,\qquad gH\gtrsim d.$$
{{smolvla:latency}}

端到端延迟包括采集、编码、传输、排队、预处理、采样与回传。新动作块按目标执行时刻对齐，并跳过已经过时的前 $d$ 步；缓冲时间需要覆盖延迟及其抖动。SmolVLA 还在关节空间过滤近重复观察，减少相似预测对执行队列的反复覆盖。异步队列机制。

End-to-end latency includes acquisition, encoding, transfer, queuing, preprocessing, sampling, and return transfer. Chunks are aligned to execution time and skip their first $d$ stale actions. Buffering covers latency and jitter. SmolVLA filters near-duplicate observations in joint space to reduce repeated queue replacement. Asynchronous queues.

SmolVLA 的计时实验中，平均任务用时由同步的 13.75 s 降至异步的 9.70 s；另一组实机任务的平均得分分别为 78.3% 与 73.3%。SmolVLA §4.6。RTC 在此基础上对下一动作块施加即将执行的动作前缀约束，再生成其余部分，直接处理块间连续性。RTC 论文。

SmolVLA’s timed experiment reduces mean completion time from 13.75 s synchronously to 9.70 s asynchronously. A separate real-robot evaluation reports mean scores of 78.3% and 73.3%. SmolVLA §4.6. RTC constrains the soon-to-execute prefix of the next chunk while generating the remainder, directly addressing boundary continuity. RTC paper.

动作块系统的连续性由队列供给、块间衔接和策略预测共同决定。队列耗尽对应计算等待，块边界跳变对应时序衔接，块内保持动作对应策略输出；三者分别由执行时间戳、chunk 标识和原始动作序列记录。RTC 执行分析。

Continuity depends on queue supply, boundary transitions, and policy predictions. Empty queues represent computational waiting; boundary jumps represent temporal transitions; holds within a chunk belong to the predicted behavior. Execution timestamps, chunk IDs, and raw action sequences identify these components. RTC execution analysis.
