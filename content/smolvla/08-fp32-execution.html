The shoulder request–feedback absolute difference averages 19.366 in recorded units. Fitting a shift on this same trajectory lowers it to 15.136 at 0.95 s; this describes alignment sensitivity rather than an independently measured actuator delay.

右臂 shoulder_lift请求与反馈的平均绝对差为 19.366，单位沿用记录。在同一条轨迹上拟合平移后，0.95 s 对应差值降至 15.136；这描述了时间对齐敏感性，与独立测量的执行器延迟有所区别。

The gripper reaches requested and measured openings of 45.987 and 44.794 but stays near closed for most frames. Feedback is globally valid and motor error fields are empty, so the large command–feedback separation requires analysis of timing and motion, beyond read validity.

夹爪请求与反馈最大开度分别达到 45.987、44.794，但大部分时间保持接近闭合。反馈有效标志正常，电机错误字段为空；较大的指令—反馈差还需结合时序与运动过程解释。

  • Visual response: at 251.12 s, replacing only the right-wrist image changes output by 53.746 Host units, versus 4.481 for replacing the full state. This result is specific to that observation and donor.

    视觉响应：251.12 s 时，只替换右腕图像使输出平均绝对变化 53.746 Host 单位，替换完整状态则为 4.481。结果对应这一观测及选定的替换帧。

  • Cross-channel state response: at 10.76 s, replacing base state changes shoulder output by 3.386; donor x.vel changes from 0.14507 to 0. This comparison measures the effect of a base-state input change on an arm-joint output.

    跨通道状态响应：10.76 s 时，仅替换底盘状态使右臂 shoulder_lift输出变化 3.386，替换来源的 x.vel 从 0.14507 变为 0。这次对照测量了底盘输入改变对手臂输出的作用。

  • Retained opening behavior: all 30 demonstrated maximum-opening windows generate opening at brightness factors 0.7, 1.0 and 1.3. This test varies brightness while preserving scene geometry and state.

    开爪行为保留：30 个示范最大开度窗口在亮度系数 0.7、1.0、1.3 下均能生成开爪。该测试只改变亮度，保留场景几何与状态。
