Observation substitutions: effect of camera and state channels观测替换：各相机与状态通道对输出的影响

At three live timestamps—start underflow (0.4 s), base advancing (10.8 s), and oscillation (251 s)—we substituted individual cameras or state channels from the nearest demonstrated arm-state frame (fixed weights, prompt, and 3 noise seeds; 117 runs total, averaging the first 25 shoulder_lift steps):

在起步越界（0.4 s）、底盘前进（10.8 s）和锯齿振荡（251 s）三个现场时刻，用最接近的训练参考帧逐项替换单路相机或分通道状态（固定权重、指令与 3 个随机种子，共 117 次重预测，统计前 25 步 shoulder_lift 变化）：

  • Oscillation (251 s) — wrist_right accounts for almost the full visual swing: Swapping only wrist_right shifts output by 53.7, matching all four cameras combined (53.2) and 12× all 18D state (4.5).

    振荡期（251 s）wrist_right 单路影响最大：仅换右腕图像即变化 53.7，与全换四图（53.2）相当，是全部 18 维状态（4.5）的 12 倍。

  • Base advancing (10.8 s) — base velocity outweighs images: Swapping base velocity alone shifts arm output by 3.4 versus 0.44 for all four images.

    底盘前进期（10.8 s）底盘速度影响大于图像：仅换底盘速度状态引起 3.4 的手臂变化，大于全换四路图像（0.44）。

  • Start offset & retained opening: Live initial left-gripper state reads 49σ from its near-constant box-holding training mean, while replaying 30 demonstrated opening windows under 0.7×–1.3× brightness still opens 30/30 times.

    起步偏离与开爪能力保留：真机初始左夹爪因训练中近常量托盒而偏离均值 49σ；同时 30 个示范开爪窗口在 0.7–1.3 倍亮度下均 30/30 正常张开，说明策略保留了开爪能力但未在振荡视角下触发。

White-box routing: what the attention layers read live白盒路由：真机现场注意力层究竟读了什么？

Opening the odd CA layers on the same FP32 100k checkpoint—borrowing MiTA’s token-selection maps and cross-frame mIoU [12]—connects those black-box substitutions directly to internal routing:

在同一 FP32 100k 权重上打开奇数 CA 层，借用 MiTA 的 token 选中率与跨帧 mIoU [12]，可以把上面的黑盒替换结果直接落到网络内部路由：

  • 0.4 s start underflow breaks the L01 state anchor: During normal moving (10.8 s), opening (51 s), and oscillation (251 s), the single state token consistently takes 40–41% of L01 mass; at 0.4 s (left gripper 49σ off), L01 state collapses to 0.4% and 8-layer average falls to 7.7%.

    0.4 s 起步越界打断了首层 state 锚点：在 10.8 s 前进、51 s 开爪和 251 s 振荡期，仅占 1 位的 state 在 L01 稳定承接 40–41% 注意力；但在 0.4 s（左夹爪偏离 49σ），L01 state 骤降至 0.4%，8 层均值跌至 7.7%。

  • Swapping only wrist_right at 251 s rewires deep routing: At L11, patch (4,4) directly on the plush toy hits 70% Top-16 selection; swapping only wrist_right (other 3 cameras, text, and state unchanged) drops L13 routing mIoU to 0.35 and shifts shoulder_lift by −54.5.

    251 s 单换 wrist_right 改写了深层路由：L11 在右腕画面中央 (4,4)（夹爪前方的玩偶处）Top-16 命中率达 70%；其余 3 路图像、文本与状态不变时，仅替换 wrist_right 即把 L13 路由 mIoU 拉低至 0.35，并使动作预测移动 −54.5。

  • Chunk-handoff drops are not frame-to-frame attention noise: Across the 40 ms sawtooth drop at 153.4 s, routing mIoU stays at 0.84 (fresh predictions −90.4 vs −90.0), and across 10 Euler steps wrist_right mass stays within 28.3–28.7%—confirming the sawtooth comes from switching from a stale old-chunk tail to a newly replanned chunk.

    块交接骤降并非逐帧注意力抖动：153.4 s 锯齿骤降前后相隔 40 ms 的两帧，跨层路由 mIoU 稳在 0.84（重预测分别为 −90.4 与 −90.0），10 步 Euler 内 wrist_right 占比也恒在 28.3–28.7%——印证锯齿来自旧块尾段切入新块起点的交接断层。
