The shoulder request–feedback absolute difference averages 19.366 in recorded units. Fitting a shift on this same trajectory lowers it to 15.136 at 0.95 s; this describes alignment sensitivity rather than an independently measured actuator delay.

右肩抬请求与反馈的平均绝对差为 19.366，单位沿用记录。在同一条轨迹上拟合平移后，0.95 s 对应差值降至 15.136；这描述了时间对齐敏感性，与独立测量的执行器延迟有所区别。

The gripper reaches requested and measured openings of 45.987 and 44.794 but stays near closed for most frames. Feedback is globally valid and motor error fields are empty, so the large command–feedback separation requires analysis of timing and motion, beyond read validity.

夹爪请求与反馈最大开度分别达到 45.987、44.794，但大部分时间保持接近闭合。反馈有效标志正常，电机错误字段为空；较大的指令—反馈差还需结合时序与运动过程解释。

Observation substitutions观测替换

For saved observations at 0.36, 10.76 and 251.12 s, select training-frame donors with nearby arm states. Replace images or selected state channels under three matched seeds: 13 conditions per observation, 117 predictions in total.

从 0.36、10.76、251.12 s 的保存观测出发，选择双臂状态接近的训练帧作为替换来源。每个观测设置 13 种图像或状态替换条件，配合三个固定种子，共生成 117 次预测。

Each condition is compared with a freshly generated baseline from the same observation and seed. The metric averages absolute shoulder-output differences over the first 25 actions, then averages the three seeds.

每种替换都与同一观测、同一种子重新生成的基线比较。指标先对前 25 步右肩抬输出差取绝对值并平均，再平均三个种子。

  • Visual response: at 251.12 s, replacing only the right-wrist image changes output by 53.746 Host units, versus 4.481 for replacing the full state. This result is specific to that observation and donor.

    视觉响应：251.12 s 时，只替换右腕图像使输出平均绝对变化 53.746 Host 单位，替换完整状态则为 4.481。结果对应这一观测及选定的替换帧。

  • Cross-channel state response: at 10.76 s, replacing base state changes shoulder output by 3.386; donor x.vel changes from 0.14507 to 0. Effects vary with the observation and replacement.

    跨通道状态响应：10.76 s 时，仅替换底盘状态使右肩抬输出变化 3.386，替换来源的 x.vel 从 0.14507 变为 0。作用随观测与替换内容变化。

  • Retained opening behavior: all 30 demonstrated maximum-opening windows generate opening at brightness factors 0.7, 1.0 and 1.3. This test varies brightness while preserving scene geometry and state.

    开爪行为保留：30 个示范最大开度窗口在亮度系数 0.7、1.0、1.3 下均能生成开爪。该测试只改变亮度，保留场景几何与状态。

Input displacement: the donors shift shoulder state by −0.792, +0.176 and −4.398 Host units. Initial left-gripper state is 49.27 training standard deviations from its mean; these input displacements are distinct from the heatmap’s output responses.

输入偏移：三个替换来源使右肩抬状态分别移动 −0.792、+0.176、−4.398 Host 单位。初始左夹爪状态距训练均值达 49.27 个标准差；这些量描述输入位置，热图则描述输出响应。
