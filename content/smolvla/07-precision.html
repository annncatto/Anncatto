精度更新与动作拟合Numerical updates and action fit

本节依次检验两个问题：训练后期的小更新是否留在保存的权重中，以及训练得到的权重能否更好地拟合示范动作。前一项比较不同训练步保存的参数，后一项固定输入与计算精度，再比较预测误差。

This section asks whether late-training updates persist in stored weights and whether the learned weights fit demonstrations better. The first measurement compares saved parameter values; the second fixes inputs and computation precision before comparing prediction error.

A 为混合存储与 BF16 autocast 的 100k 模型，B 为 FP32 方案的 100k 模型，两者从同一任务检查点在同一套 150 回合数据上训练。C 在 B 之后以恒定学习率 5×10⁻⁷ 继续 20k 步，用于观察后续进展。

A is the mixed-storage/BF16-autocast model at 100k updates; B uses the FP32 recipe for 100k updates from the same task initialization and 150-episode data. C continues B for another 20k updates at a constant learning rate of 5×10⁻⁷.

参与优化的参数范围Parameters included in optimization

检查点中的权重和 Adam 状态对应 99,880,992 个可训练参数元素，其中动作专家约 98.25M、外部投影约 1.64M。约 350.17M 的视觉与其余 VLM 参数冻结：它们参与前向计算，优化器更新动作专家和投影层。

Saved weights and Adam states identify 99,880,992 trainable elements: about 98.25M in the action expert and 1.64M in external projections. About 350.17M vision/VLM elements are frozen: they contribute to forward computation while the optimizer updates the expert and projections.

事后检查时，先对齐参与比较的数值类型，再逐元素核对冻结权重与任务初始化值，结果一致。这里的类型对齐用于区分格式转换与训练更新；冻结参数的训练存储类型由计算方案决定，保留小更新所需的 FP32 累计则针对可训练参数。

For the post-training check, dtypes are aligned before comparing frozen weights element by element with task initialization; the values match. This separates format conversion from training updates. Frozen storage follows the compute recipe; FP32 accumulation to retain small optimizer updates concerns trainable parameters.

For A, compare the saved weights at steps 95k and 100k, matching tensor names and element positions. An element stored as 0.0200195 and 0.0201416 counts as changed; equal values count as unchanged.

起止值相同，可以对应中间始终不变，也可以对应中间改变后又回到原值。逐步更新次数与每次舍入是否丢失增量，需要逐步记录；这里统计的是两个保存时刻的数值差异。

Equal start/end values can describe either an unchanged value throughout or a value that changed and returned. Counting effective updates or rounding losses requires per-step records; this measurement compares two saved times.

这种差异按参数存储类型分组。低学习率使优化器增量变小；若增量不足以使当前 BF16 权重越过舍入边界，更新结果写回参数张量后仍是原值。FP32 的可表示数更密，能够保留更小的增量。

This contrast groups parameters by storage dtype. Lower learning rates reduce optimizer increments; when an increment does not cross a BF16 rounding boundary, writeback leaves the stored value unchanged. FP32 has finer spacing and can retain smaller increments.

上述结果呈现了小更新在 BF16 写回时被舍入这一机制预期的现象：BF16 组的保存值很少变化，FP32 组则大多不同。对应原理在本文顶部默认折叠的“数值类型”章中，见“更新舍入”及其 100 步累计交互图；A/B 的完整方案同时改变权重存储、Adam 状态和计算精度，拟合结果按整套方案比较。

The observed dtype contrast matches the expected pattern of small updates being rounded away at BF16 writeback: few BF16 values differ, while most FP32 values do. The A/B recipes jointly change weight storage, Adam-state dtype and compute precision, so the fit comparison evaluates the complete recipes.

贴边目标与越界预测Boundary-adjacent targets and output crossings

C 的右肩抬在 4,500 个预测位置中有 153 个低于 −100，比例 3.40%；A 为 390 个、8.67%。两组越界全部位于回合起始窗口，对应示范目标为 −99.7447 至 −98.9787，已贴近下限。

C predicts shoulder values below −100 at 153 of 4,500 positions, or 3.40%, versus 390 or 8.67% for A. Every crossing in both groups occurs in start windows, with demonstrated targets between −99.7447 and −98.9787 near the lower bound.

该通道训练标签的均值为 −53.0387、标准差为 60.9626，下限 −100 对应标准化值约 −0.77033。网络使用线性速度头与 Euler 更新生成连续动作，反归一化 $a=\mu+\sigma z$ 把数值恢复到原尺度；这条仿射变换没有将结果投影到关节上下限。

This channel has training mean −53.0387 and standard deviation 60.9626; its −100 limit corresponds to standardized value approximately −0.77033. A linear velocity head and Euler updates generate continuous actions, restored by $a=\mu+\sigma z$, an affine map without projection onto joint bounds.

  • 贴边目标的小误差也可能跨界：C 的越界平均超出下限 0.235，最大 1.219。更准确的轨迹拟合减少了越界数量，输出约束仍是独立的接口要求。

    Small errors near a boundary can cross it: C's mean overshoot is 0.235 and maximum is 1.219. Better fit reduces crossings while output constraints remain a separate interface requirement.

  • 限幅与策略改善承担不同作用：单独裁剪 C 的右肩抬，MAE 从 1.2488 变成 1.2408，仅改善 0.64%。按字段实施的限幅保证数值范围，动作方向、时机与轨迹仍由策略生成。

    Clipping and policy improvement serve different roles: shoulder-only clipping changes C's MAE from 1.2488 to 1.2408, a 0.64% improvement. Field-specific limits enforce ranges; the policy still determines direction, timing and trajectory.

  • 内部维度与监督范围也需分开：源码确认训练 loss 只保留 18 个真实动作维，而采样对全部 32 维作积分。14 个补零维的状态演化是后续可独立干预的内部通路，其对当前越界的贡献按受控对照另测。

    Internal dimensions and supervision differ: source inspection confirms loss on 18 real dimensions while sampling integrates all 32. The 14 padded dimensions provide a separate internal pathway for controlled intervention to measure their contribution to crossings.
