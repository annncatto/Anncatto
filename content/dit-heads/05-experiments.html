数据预处理Data preprocessing

本次 MTD 的动作采用 MIN_MAX 归一化，前向速度范围为 $[-0.15,0.15]$，对应映射为：

This MTD run uses MIN_MAX action normalization. The forward-velocity range $[-0.15,0.15]$ gives:

$$z_x=\frac{v_x}{0.15},\qquad\widehat v_x=0.15\widehat z_x.$$

RGB 使用 CLIP 图像预处理，连续状态与动作按各自统计范围逐维处理。前向停止标签为 $z_x=0$，前进与后退标签分别为 $+1$ 与 $-1$。反归一化保持这一维的零点，并将预测恢复为原始速度尺度。

RGB uses CLIP preprocessing; continuous state and actions use their respective per-dimension ranges. Forward stop maps to $z_x=0$, with forward and reverse labels at $+1$ and $-1$. The inverse transform preserves zero and restores the original velocity scale.

轨迹分析Trajectory analysis

以下曲线来自 Multi-Task DiT 的 150 条示教、200k 步模型，评估标识为 20261023_101851，episode 0，共 1,825 帧、60.8 s，时间轴采用 30 Hz 录制坐标。

These curves use the 150-demonstration, 200k-step Multi-Task DiT evaluation 20261023_101851, episode 0: 1,825 frames over 60.8 s on a 30 Hz recording timeline.

  • 策略指令（Target）：action 记录策略动作经反归一化等后处理后的单步控制请求，表示要求关节到达的位置或底盘达到的速度。
  • 实测反馈（Pre-request feedback）：observation.state 记录机器人上报的关节位置、底盘速度等状态，采样早于本次策略调用与指令发送。
  • Policy command (Target): action records a single-step control request after denormalization and other postprocessing, specifying requested joint positions or base velocities.
  • Measured feedback (Pre-request feedback): observation.state contains robot-reported joint positions, base velocities, and other state, sampled before the current policy call and command transmission.

采集顺序为读取状态、调用策略生成或取出队列动作、发送指令。同一行中的两条信号分别描述当前状态和接下来请求的动作，响应体现在后续反馈中。

The loop reads state, calls the policy to generate or dequeue an action, then sends the command. A row pairs the current state with the next requested action; its response appears in subsequent feedback.

肩肘指令在约 20–37 s 与 43–55 s 出现两段大幅变化，夹爪在约 27–29 s 和 50–52 s 出现明显开合指令。右臂七个通道各自最大的三次相邻指令变化共 21 次，全部落在 25 帧整数倍的位置，对应录制时间中的 0.833 s 网格。

Shoulder/elbow commands change substantially around 20–37 s and 43–55 s, with gripper-opening commands around 27–29 s and 50–52 s. All 21 events selected as the three largest adjacent command changes per right-arm channel occur at multiples of 25 frames, a 0.833 s grid in recording time.

大幅肩肘轨迹与较小腕部阶跃叠加，指令刷新节律与片段中的停顿需要分别辨认：指令差异影响切换时的跳变，计算等待影响停顿时间。夹爪指令在这条轨迹中达到 41.804，表明该次记录包含明确张开指令；投放阶段的失败还涉及这些指令出现的时机与物体接触状态。

Large shoulder/elbow trajectories coexist with smaller wrist steps. Command discontinuities and computational waiting affect jumps and pauses separately. Gripper commands reach 41.804 in this recording, establishing that explicit opening commands occur; release outcomes also depend on when they occur and the contact state.
