策略与动作头Policy and action head

完整策略将观察转为动作：$c=g_\phi(O,\ell)$ 提取条件，$G_\theta$ 根据条件生成动作块，执行器从动作块中取出当前控制量。动作头的“头”表示它位于视觉语言主干之后；其内部可以包含多层 Transformer、噪声采样和数值积分。

A complete policy extracts conditions $c=g_\phi(O,\ell)$, generates a chunk with $G_\theta$, and selects controls for execution. An action head sits after the visual-language backbone; it can contain a multilayer Transformer, random sampling, and numerical integration.

$$c=g_\phi(O,\ell),\qquad A=G_\theta(z;c),\qquad a_t=\operatorname{Queue}(A)_t$$

直接回归动作的 MLP 将条件特征映射为动作；扩散网络中的 MLP 还承担动作嵌入、时间嵌入、逐 token 前馈和输出读出。编码器与解码器描述输入输出的作用，网络结构可以是线性层、MLP 或 Transformer。以 MTD 为例，$18\to512$ 的输入投影编码每步动作，$512\to18$ 的输出投影读出噪声预测；动作时间位置之间的交互由中间的注意力层完成。

An MLP can directly regress actions or serve as an embedding, time encoder, tokenwise feed-forward module, or output readout inside diffusion. Encoder and decoder describe roles. In MTD, an $18\to512$ projection embeds each action and a $512\to18$ projection reads out predicted noise; attention mixes action positions between them. MTD implementation.

宽度、头数与层数Width, heads, and depth

设动作特征为 $X\in\mathbb R^{B\times H\times d}$。$B$ 为批量，$H$ 为动作位置数，$d$ 为每个位置的隐藏维度。注意力头数 $h$ 决定每头宽度 $d_h=d/h$；层数 $L$ 表示 Transformer block 重复的次数。一个动作头可包含六层 Transformer，每层再包含八个注意力头。MTD 的 $H=32,d=512,h=8,L=6$ 对应每头 64 维。

For $X\in\mathbb R^{B\times H\times d}$, $B$ is batch size, $H$ action positions, and $d$ hidden width. With $h$ heads, each has width $d_h=d/h$; $L$ counts blocks. One action head can contain six Transformer blocks, each with eight attention heads. MTD uses $H=32,d=512,h=8,L=6$, giving 64 dimensions per head.

$$Q_j=XW_j^Q,\ K_j=XW_j^K,\ V_j=XW_j^V,\qquad W_j^{Q,K,V}\in\mathbb R^{512\times64}$$
$$\operatorname{head}_j=\operatorname{softmax}\!\left(\frac{Q_jK_j^\top}{\sqrt{64}}\right)V_j,\qquad Y=\operatorname{Concat}(\operatorname{head}_1,\ldots,\operatorname{head}_8)W^O$$

每头投影都读取完整 512 维输入，学习不同的特征组合。Q、K、V 分头后形状为 $[B,8,32,64]$，每头得到 $32\times32$ 的动作关系矩阵；拼接与输出投影再混合各头特征。头数改变关系建模的子空间，隐藏维度改变每个 token 的容量，增加层数则增加连续变换的深度。

Each projection reads all 512 input features. Q/K/V reshape to $[B,8,32,64]$, producing a $32\times32$ action-relation matrix per head; concatenation and output projection mix the results. Head count changes relational subspaces, width changes token capacity, and depth adds successive transformations.

条件注入Conditioning

Cross-Attention 以动作特征作 query，以图像、语言等条件 token 作 key/value。每个动作位置根据自身 query 读取不同条件信息。adaLN 在层归一化中将条件向量映射为通道尺度、偏置与残差门控，并广播到动作位置。两者可以组合使用，例如跨注意力读取多模态内容，同时由噪声水平调制归一化。

Cross-attention uses action queries and condition keys/values, allowing each action position to read relevant condition content. adaLN maps a condition vector in layer normalization to channel scales, shifts, and residual gates shared across action positions. They can coexist: cross-attention reads multimodal content while noise level modulates normalization.

$$\operatorname{CA}(X,C)=\operatorname{softmax}\!\left(\frac{XW_Q(CW_K)^\top}{\sqrt{d_h}}\right)CW_V$$
$$\operatorname{adaLN}(x;c)=(1+\gamma(c))\odot\operatorname{LN}(x)+\beta(c),\qquad x^+=x+\alpha(c)\odot F(\operatorname{adaLN}(x;c))$$

adaLN-Zero 将残差门控等调制层的末层初始化为零，使 block 从接近恒等映射开始训练。MTD 将视觉、状态、语言和扩散时间拼成条件向量，逐层生成六组调制量；MDT、GR00T 和 Spirit 还使用跨注意力保留条件 token 的读取路径。

adaLN-Zero initializes modulation outputs to zero, starting blocks near identity. MTD forms a vector from vision, state, language, and diffusion time to produce six modulation groups per block. MDT, GR00T, and Spirit also use cross-attention to retain condition-token access.

扩散与流匹配Diffusion and flow matching

DDPM 训练在归一化动作 $A$ 上随机选择噪声等级 $k$，加入高斯噪声，再预测所加噪声。一次训练样本只需评估一个随机噪声等级；推理从噪声动作块开始，重复去噪网络与调度器更新。这里 $k$ 是生成过程的索引，$H$ 中的位置对应真实动作序列。

DDPM training samples a noise level $k$, corrupts normalized actions $A$, and predicts the noise. Training evaluates a sampled noise level; inference repeatedly applies the denoiser and scheduler. The generation index $k$ is distinct from positions in the real action sequence.

$$A_k=\sqrt{\bar\alpha_k}A+\sqrt{1-\bar\alpha_k}\epsilon,\qquad\mathcal L_{\mathrm{DDPM}}=\mathbb E\|\epsilon_\theta(A_k,k,c)-\epsilon\|_2^2$$

流匹配训练回归噪声与动作之间的向量场。以 MTD 的 $\sigma_{\min}=0$ 为例，$\tau=0$ 为噪声，$\tau=1$ 为动作；采样使用训练好的向量场，从 0 向 1 积分。SmolVLA 的实现采用相反的时间方向，两种记法都需要让路径、训练目标与积分方向一致。

Flow matching regresses a vector field between noise and actions. In MTD with $\sigma_{\min}=0$, $\tau=0$ is noise and $\tau=1$ is data; sampling integrates the learned field from 0 to 1. SmolVLA uses the opposite time orientation, with its path, target, and integration direction matched accordingly.

$$X_\tau=(1-\tau)Z+\tau A,\quad u=A-Z,\quad\mathcal L_{\mathrm{FM}}=\mathbb E\|v_\theta(X_\tau,\tau,c)-u\|_2^2$$
$$X_{\tau+\Delta\tau}=X_\tau+\Delta\tau\,v_\theta(X_\tau,\tau,c)$$

Flow Matching改变生成路径与预测目标；DiT 规定网络骨架。相同 Transformer 可以配合不同生成目标。DDIM 则保留扩散训练目标，改变推理更新与选取的噪声等级，以减少网络评估次数。

The flow-matching objective specifies a path and prediction target; DiT specifies network architecture. A Transformer can support different objectives. DDIM retains diffusion training while changing inference updates and noise-level selection to reduce network evaluations.

连续动作与离散标签Continuous outputs and discrete labels

底盘示教可以只取停止、前进和后退几个速度值，扩散与流匹配仍在连续张量空间生成动作。线性归一化保存这些标签之间的对应关系，训练路径中的中间值属于噪声过程；执行时发送最终生成结果。有限的条件辨识能力、去噪精度与采样近似都可能使最终结果偏离离散标签。

Demonstrations can contain discrete stop/forward/reverse velocities while diffusion and flow matching generate continuous tensors. Linear normalization preserves the label mapping. Intermediate training values belong to the noise path; execution uses the final sample. Conditioning, denoising accuracy, and sampling approximation affect its distance from discrete labels.

以单个噪声回归问题为例，平方损失的最优解为 $f^*(x,k,c)=\mathbb E[\epsilon\mid x,k,c]$。它是噪声等级与条件下的后验均值，完整迭代仍可恢复多模态动作分布。把每步的均值回归直接解释为最终动作被平均，会遗漏整个采样过程。

For squared noise-regression loss, $f^*(x,k,c)=\mathbb E[\epsilon\mid x,k,c]$. This conditional mean is evaluated within a generative process that can still recover multimodal actions. Final behavior must be assessed after the complete sampling trajectory.

层数与模型规模Depth and model size

$$P_{\mathrm{total}}=P_{\mathrm{vision}}+P_{\mathrm{language}}+P_{\mathrm{action}}+P_{\mathrm{projection}},\qquad P_{\mathrm{block}}\approx12d^2+P_{\mathrm{condition}}$$

上式的 $12d^2$ 对应四组注意力投影与扩张比为 4 的前馈层，仅作结构量级估算。条件投影、跨注意力及不同宽度会改变系数。层数描述变换深度，宽度决定矩阵大小；完整模型参数还包括视觉语言主干。

The $12d^2$ estimate covers four attention projections and an expansion-4 feed-forward layer. Conditioning and cross-attention add terms. Total parameters also include the backbone, so depth, width, head parameters, and complete-model size should be listed separately.
