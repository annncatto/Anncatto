## 用户希望工具解决什么问题

工具围绕轻量化概念设计，帮助比较设计参数和计算指标：

- 一页中间展示清楚的机器人模型和运动，左右分别调整结构、长度、材料、自由度、电机位置及驱动条件。
- 连杆长度可全局或逐构件自定义，关节间距需要明确，模型避免重叠与穿模。
- 主要结果一行集中展示，向下阅读对应公式、代入、适用条件和分析判断。
- 突出装配质量、负载惯量、反射惯量、刚度／变形、固有频率、力矩需求及反向驱动性。
- 机械臂直接叫“机械臂”；夹爪开合与旋转自由度分开说明，避免“6+1”作为名称。
- 足端和末端工具可使用协调的角色颜色，帮助辨认随动质量。
- 减少逐个关节摆姿态的控制，不把复杂工程图挤在右下角。
- 参考开源 Draft 项目的关节树、端部退让与执行器包络组织方式，实际模型与计算保持同源。

## 本地版本已经做了什么

`content/lightweight-lab.html` 与 `src/lightweight-lab.ts` 构成当前界面：顶部结果条，左侧结构／材料，中央 Three.js 模型，右侧驱动／载荷；下方是计算与解释。页面允许向下滚动。

- 支持四足、人形和机械臂的默认构型及部分自由度组合。
- 支持构件长度、单构件覆写、关节间距、截面、材料、末端质量与负载；电机包络和质量可独立输入。
- 构件、执行器、传动、足端／工具、负载使用角色配色；提供正视、侧视、三维与视角适配。
- 支持设为对照，比较结构与驱动变化；比较时统一当前载荷、加速度、误差限值和目标频率间隔。
- 参考姿态的计算结果在运动播放时保持固定，避免把姿态变化误读为设计参数收益。
- 支持 JSON、URDF、MJCF、GLB、PNG。JSON 还保留工作条件和对照信息。
- 已从当前界面移除旧 SVG／DXF 工程图操作。`concept-drawing.ts` 留在仓库中，并不表示当前界面仍使用它。
- 本地持久化键为 `anncatto.lightweight-design.v3`。测试默认模型时注意旧浏览器设置的影响。

## 计算口径与限制

| 结果 | 当前实现 | 继续开发时保持的边界 |
| --- | --- | --- |
| 装配质量 | 全部组件质量求和，杆件、执行器等分类统计 | 近端移位增加的传动和支承也要计入 |
| 负载惯量 | 随动子树的转动张量旋转及平行轴折算 | 不能仅用一个末端点质量替代整条链 |
| 反射惯量 | 输出端 `N² Jm`，并与负载惯量比较 | 改减速比不自动改变电机实体质量；参数需明确 |
| 端部柔度 | 可弯曲净杆段的梁柔度，加输出端转动弹簧柔度 `L²/kθ` | 按真实弯曲轴处理截面，不总取强轴；连接段视为刚性 |
| 第一模态估算 | 以静挠度形状做 Rayleigh 估算，含分布杆质量、下游等效质量及相关转子项 | 当前显示 `fn/fb` 的频率间隔，不是辨识得到的闭环带宽 |
| 输出力矩需求 | 指定惯性项、重力、横向载荷和摩擦量级相加 | 未求完整 Coriolis 耦合、接触力分配或驱动器热限制 |
| 反驱门槛 | 重力补偿条件下，电机／齿轮摩擦及反向效率的输入估算 | 不是实测反驱性能或碰撞安全等级 |
| 强度与变形 | 指定构件的梁模型和输入工况初筛 | 不等同于整机有限元、屈曲或疲劳验证 |

计算对象由选中构件和实际驱动轴共同确定。界面显示参考姿态、构件、关节轴、载荷和加速度；更换输入或对照时核对这些条件。

- 测试对默认三种构型、两种电机位置扫描多个周期采样；另覆盖部分自由度与负载组合。
- 包络检查使用保守 OBB，排除相邻结构的预定连接界面、`collar` 和 `belt`；独立电机仍参与检查。它不等同于连续三角网格接触检测，也不能证明所有自定义尺寸均无穿模。
- MuJoCo 中存在站立／姿态保持和 FK 验证；历史控制器及短期训练策略未通过持续行走评估。不要把运动学预览换个标签当作物理验证结果。
