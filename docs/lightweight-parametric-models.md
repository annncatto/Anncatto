核对日期：2026-11-04。工作位于 `draft/lightweight-design-workbench`，仅本地。本文记录参数定义、质量假设和验证入口；原模型及许可见[模型来源](lightweight-model-sources.md)，运动与闭环测试口径见[控制与验证](lightweight-control.md)，原零件结构资料见[承力件来源](source-structure-sources.md)与[CAD 截面校核](lightweight-structural-checks.md)。

## 原模型与派生模式

`sourceMode: 'derived'` 从原模型的完整关节树生成参数化概念方案，尺寸保存在 `sourceDimensions`，单位为 m。`sourceMode: 'original'` 或未设置该字段时，继续采用原模型；存储中的派生尺寸不会修改原模型。`sourceParameterDefinitions(model)` 始终从未经尺寸编辑的源模型取得基准，返回 `id`、中英文名称、当前值、基准、输入范围及分组，不以已经修改的模型再次缩放。

默认派生值逐节点保留所选源模型的关节偏移、固定旋转、轴向、参考角、限位、限矩、限速、质量、质心与中心惯性张量。Alohamini 默认源物性已改用同一 URDF 绑定的 LIBERO CAD 名义惯量包；`armInertia: 'urdf'` 仍可复现旧 URDF 预算。显示采用连接线段、关节符号、源主躯干／基座的几何外框和原足端，避免把变长的概念杆件画成仍然可制造的原 CAD 外壳。除原足端接触几何外，碰撞几何也采用简化包络；因此**默认尺寸相同不代表碰撞模型相同**，原模型的闭环通过记录不能直接用于派生模型。

界面提供“原模型”“参数化概念设计”“通用梁构型”三类方案。前两类使用相同的源机构树；第三类保留旧通用机构、梁截面、材料与自由度控制。三种机器人各自保存三类方案的设计、工况、所选对象及对照，切换或刷新后恢复各自输入。存储键 `anncatto.lightweight-profiles.v1` 与现有活动方案键 `anncatto.lightweight-design.v3` 并存，旧通用方案仍归入通用梁构型，不用源默认值覆盖。

“恢复源尺寸”只清除尺寸编辑，保留负载与其他输入；全局“复位”恢复当前类型的方案，其他类型的快照保留。派生／通用方案复位不清除独立的原件 CAD 校核输入；原模型复位仍重置其 CAD 输入。

## 承力杆、材料与剩余总成预算

当前实现标识为 `source-members-v1`。原先 `fixed-link-mass-affine-v1` 的固定整 Link 质量方案是上轮状态；当前选定承力杆的材料、截面与长度参与质量计算，其余总成保留独立预算。默认源尺寸、参考材料和参考截面下，原节点质量、质心、完整惯性严格保持原值。

可设计杆件为 Go2 每腿大腿／小腿共 8 段，RP1 每腿髋偏航—膝及膝—踝共 4 段，Alohamini 上臂／前臂共 2 段。腕部、电机壳和安装偏置不自动当作梁。源模型仍可选全部关节；材料页另外选择设计杆件，选中没有截面的关节时也能继续编辑已选杆件。

基准梁取 **12×18×0.8 mm 箱形截面，有效长度为关节中心距的 80%**，两端各留 10% 刚性连接区。这是公开的概念初值，不是原零件 CAD 或由惯量反推的外形。Go2／RP1 采用铝合金参考，Alohamini 采用 ABS 参考；基准仅定义如何分配源质量预算，不声称所有原件均使用该材料。每个杆件可改为箱形管、圆管或实心矩形，并修改宽、高、壁厚、材料、密度、E、G 和强度。

为避免同时计算原总成和新增梁的质量，先从原 Link 扣除基准梁的质量、一阶矩、完整二阶矩，得到剩余刚体预算，再加上当前杆件：

```text
m_r = m_source − m_reference
m_r c_r = m_source c_source − m_reference c_reference
S = tr(I)/2 · Id − I
H = S + m c cᵀ
H_r = H_source − H_reference
S_r = H_r − m_r c_r c_rᵀ
```

`S` 是质心处质量二阶矩，`H` 是相对于 Link 原点的二阶矩。剩余质量必须为正、`S_r` 必须半正定，单凭总质量为正不能通过校验。剩余项不是已识别的电机质量，不能把其显示名称改成电机／轴承实测拆分。

尺寸变换 `x′ = A x + b` 作用于剩余项：`c_r′ = A c_r + b`、`S_r′ = A S_r Aᵀ`，其质量不变。新杆件使用当前截面和材料计算 `m_b = ρ A_section L_cut`，由均匀梁的完整惯性与剩余项重新合成 Link 质量、质心及中心惯量。未定义承力杆的 Link 保持原来的固定质量仿射分布。参考梁始终从未经编辑的源数据重建，不用已经修改的方案重新建立基准。

`Component.inertia` 保存剩余项的完整局部中心张量；它是不可见、无碰撞的质量数据，不通过虚构盒体尺寸表示。`member.inertialComponents` 必须同时重组出 Link 的质量、COM 和六项惯性。截面载荷／模态估算把剩余刚体按 COM 的杆轴投影站位连接到概念杆，这是当前概念连接假设，不是原机构载荷路径辨识。

材料库包含铝、镁、钢、钛、CFRP 与 ABS。ABS 的 ρ=1058 kg/m³、E=2 GPa、屈服强度32.5 MPa采用 [Stratasys ABS-M30 2025 数据表](https://www.stratasys.com/contentassets/5460e85552cf40a097148d125e8be84f/mds_fdm_abs-m30_0925a.pdf)第7页与第10页 F770／T14／XZ／0.25 mm 的参考值；G按各向同性假设 ν=0.35 推导。用户只确认了 ABS 材料类别，这些参数不是其打印件的实测性能，也不用于倒推填充率。原 CAD 面板已有的有效质量分配密度继续独立保存。

变换规则如下：

- 单个关节中心距沿原向量方向 `e` 伸缩，`A = Id + (s−1)eeᵀ`；原偏移的横向分量和非共线方向不会被改写成竖直直杆。每侧使用同一倍率。
- 根髋间距沿指定 X／Y 轴围绕原安装中点伸缩。所属 root 的质量分布和全部直接子关节同步变换；RP1 的腰部安装点也属于 root 的直接子节点。
- Aloha 肩 Y／Z 与 TCP X／Y／Z 使用所属 Link 的整体平移 `b`，避免用很小的有符号偏移作除数。该 Link 的全部直接子安装点一起移动；修改 TCP 偏移因此也影响同一 J6 Link 上的夹爪和摄像头安装点，不是仅更换一个无质量坐标标记。
- 子 Link 自身的坐标系旋转、关节轴、限位、参考角及驱动限制保持不变。所选 Link 的变换通过其子关节位置传递到后续骨架。

显示中的主躯干／基座盒体来自源几何外框，连接圆柱按实际关节原点生成；关节符号只帮助识别轴位。惯性不能反推出零件外形，因此不以惯性协方差生成碰撞盒。连接碰撞圆柱在端部退让，保留源足端接触几何；原本没有碰撞体的 RP1／Aloha 基座只显示外框。其余显示包络不承担重新估算源质量的职责；概念承力杆则按当前截面显示。圆管在 URDF／MuJoCo 中使用圆柱外包络，质量与惯量仍按空心截面计算。

## 结构与运动结果的使用范围

原 Aloha 上／前臂与 RP1 M447 的 CAD 截面只描述其固定版本原件。尺寸参数变化后，这些原件的 A、I、材料、夹持条件及结构结果不会自动变成派生构件的数据；它们只能保留为原件参考。当前派生模型的应力、变形和材料比较采用上述独立概念截面。输出转动刚度是可编辑假设；源未声明的转子惯量仍为未知，不据此给出整链模态数值。原件 CAD 校核在材料比较下方单列为“原尺寸零件弯曲参考”。

每轴限矩／限速仍来自各源 URDF，表示该描述中的限制，不能直接称为连续热额定能力。派生方案的尺寸改变了重力力矩、负载惯量、可达空间和接触几何关系；旧动作或旧测试结果不随参数复制。原生足端几何保留也不保证新的简化非足部碰撞模型具有相同闭环表现。

## XYZ 偏置、连接端段与 LIBERO 物性（2026-11-03）

构型输入现为 Go2 15 项、RP1 23 项、Alohamini 26 项，其中长度和 XYZ 是同一几何向量的不同表示，不是相互独立的自由度。每条主要连接的长度、三个父连杆局部 XYZ 分量都可拖动或精确输入。`editSourceDimension()` 统一编辑；改长度沿当前向量伸缩，改坐标更新实际欧氏距离。导入的长度与 XYZ 若不一致则拒绝，不按字段处理顺序覆盖。旧的仅长度设计保持原方向缩放。

- Go2：原安装间距、髋侧偏、大腿和小腿；新增髋共同安装 Z、髋侧偏／大腿／小腿的 XYZ。

- Alohamini：基座、肩、上臂、前臂、两级腕部和 TCP；新增肩 X 与上述关节连接的 XYZ。TCP 输入仍表示以 TCP 为基准的末端总成平移，不是夹爪与摄像头的独立零件重装配。
