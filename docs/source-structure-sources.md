## M447 坐标与截面数据

生成脚本为 [`scripts/models/import-rp1-structure.py`](../scripts/models/import-rp1-structure.py)，输出 [`m447-sections.json`](../public/models/rp1-24/structural/m447-sections.json)。原工程文件、材料 BOM 和许可保留在同目录 `source/`。使用现有 OCP 环境，不安装依赖：

```sh
/home/anncatto/miniconda3/envs/alohamini/bin/python scripts/models/import-rp1-structure.py
# 已有原件后的离线再生成
/home/anncatto/miniconda3/envs/alohamini/bin/python scripts/models/import-rp1-structure.py --offline
```

脚本绑定当前 URDF 原字节 SHA-256 `d0c86d45773974d91445b728d148ecec965267746ec73e71afc6a7ffbce708d5` 和 `right_knee_link.STL` SHA-256 `ffe17fc9ba1614ae86610dc1b657461a3d1d70350729296c9210f68f3934d01d`。任何变化均须重新检查注册。

三对正交平面确定零件到 `right_knee_link` 的旋转为单位阵，平移为 `[0.001808283856907,-0.030809000134468,-0.001165999621153] m`。独立检查使用半径 9 mm 的踝孔轴，其变换后轴线与当前 URDF 右踝俯仰轴的距离约 **1.183 µm**。这验证坐标对应；并不宣称两个版本的全部表面一致。原 CAD 顶点到源显示网格的近邻表面距离初查有局部差异，不能把显示网格当作制造验收标准。

截面参考线使用当前 URDF 膝原点 `[0,0,0]` 到踝俯仰原点 `[0.03131,-0.030809,-0.30533] m`，长度 **0.308473531249 m**。它来自实际关节坐标，不采用视觉外框或主惯性轴猜测。参考线仍不等于已识别的夹持边界、承力中性轴或完整载荷路径。

计算采用原始有效实体与平面的布尔交集，保留孔洞、筋板和分离截面；布尔运算显式采用非破坏模式，避免连续切片修改输入子形状和容差。对原生曲面进行显式误差目标 `1e-9` 的自适应数值积分，不用三角网格面积替代。输入单位 mm，输出转成 SI。面积惯性矩为截面质心处的 `Iuu`、`Ivv` 与面积乘积 `Iuv=∫uv dA`；极面积惯性矩不是 Saint-Venant 扭转常数。

计划站位为参考跨的 5%–95% 共 81 站，最终生成 **82 个有效截面**，实际范围为 `s=15.4236766–293.0498547 mm`。其中请求位置 `244.4652735 mm` 的布尔交面未通过原生拓扑检查，采用两侧 `244.3652735`／`244.5652735 mm` 两个有效截面，记录实际位置和调整原因；没有把无效截面改成零面积。调用方必须按 `sM` 实际间隔积分。`boundaryUVm` 共 **13437 个点**，是相对截面质心的无序边界采样集合，弦偏差目标 10 µm，用于线性截面应力极值，不是可直接连成轮廓的有序多边形。

完整几何轴域另用 96／192 点 Gauss–Legendre 积分截面积，与原生 CAD 体积比较；数值、误差和实际节点数量记录在 `sectionVolumeConsistency`，不以展示采样覆盖整个零件体积。若某个积分节点落入布尔拓扑异常区，仅为体积积分使用两侧有效截面的线性插值，记录区间半宽和两侧面积；这些插值不进入实际截面 profile。提取器另用有矩形通孔的实体盒核对 A、Iuu、Ivv 与 Iuv，结果与解析式在浮点误差范围一致。

最终原生 CAD 体积为 **120620.263728 mm³**；96 点积分相差 **0.391113%**，192 点相差 **0.161587%**。两档分别有一个积分节点使用邻近有效截面插值：`s=323.314233 mm` 的半宽为 0.25 mm，`s=323.231063 mm` 的半宽为 0.1 mm。它们位于发布的截面采样范围之外，只影响整体体积复核。该误差检查验证几何截面积分的一致性，不代表整件应力、连接或有限元精度已经验证。

结果文件为 1,028,507 bytes，SHA-256 **`0c2c1aa87b68dd88ca383d83a6f5e0128f76a7f976fca084964aa8bb73972728`**。82 站全部通过正面积、截面惯性矩正定、位置单调和边界数值有限检查；原件 Git blob／SHA-256 全部相符。带孔盒的面积及惯性矩解析对照最大相对误差为 `1.65e-15`。

名义密度 2700 kg/m³ 来自 [Alumeco EN AW-6061 板材资料，2025-04-08](https://www.alumeco.com/media/1p5lryc3/6061_sheet.pdf)，不由 STL 或整体 URDF 质量反推。`cadNominalMassKg=ρV` 为 **0.325674712066 kg**，是 CAD 名义质量，未称重、未作动力学辨识，也不覆盖原 URDF 的总成质量。材料牌号由 RP1 工程图和 BOM 指定；供应商通用材料表不能替代实际批次证明。

同一材料表给出的弹性模量为 **70000 N/mm²，即 70 GPa**，可作可编辑的名义初筛值。其 T6 行将 `0.4≤t<400 mm` 的板材性能汇总为 `Rp0.2` 最低值 **220–240 MPa**，未列出各厚度分档。**240 MPa 不能由此直接认定为 M447 的保证屈服强度**：图纸中的局部壁厚不是原始毛坯采购厚度，当前也未取得该件产品形态、毛坯规格或批次材质证明。若界面使用 240 MPa，必须标成可编辑初筛假设；220 MPa 是该供应商表覆盖范围中的较低值，同样不能替代实际材料验收。这里的强度是 0.2% 规定塑性延伸强度，不能混用抗拉强度 `Rm`。

## 当前可计算范围与具体缺口

M447 可以在明确的夹持位置、施力位置、力／力矩和材料弹性参数下，进行**单零件的固支弯曲近似**。它只是装配中的一个承力件：另一半壳体、螺钉、轴承、电机外壳共同承担载荷。未确定这些连接和分担时，不能把关节总载荷称为该零件实载，也不能把零件弯曲模态称为整腿／关节固有频率。

- 连接机械刚度、夹持边界和载荷分配尚未从这些资料中确定；相关字段保持 `null`。控制器 PD 增益不得当作机械扭转刚度，不能填统一默认值使计算看似完整。
- 变截面、开孔、加强筋和局部厚壁需要检查梁近似适用范围；局部孔边应力集中、接触／螺栓、剪切变形与扭转不能由 A 和两个 I 自动补齐。更完整结果需装配有限元和连接模型。
- M448 原件含 2 个不可定向面和 2 个自交线环。在副本上运行 `ShapeFix_Shape`，最大容差分别 0.001／0.01／0.05 mm，仍未通过 B-rep 检查，体积数值基本不变。这些尝试没有覆盖原件，也没有进入有效 profile。M667／M663 仍需进一步导入／修复及独立几何校核。
- [ROMOMO 官方资料](https://github.com/Roboparty/ROMOMO/tree/a9140df7b4e93631d755b5afa1e2c7dff2cfe439)确有 10062／6562 的厂家台架、效率、温升和转矩数据，本次实际读取了相关 PDF；在这些已读资料中未找到可直接采用的总成扭转刚度、连接刚度或回差曲线。不能由额定转矩和减速比倒算刚度。
