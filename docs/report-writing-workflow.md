# 正式报告写作规范

适用于课程工程报告、实验报告与论文初稿。正文面向首次阅读的评审者，围绕研究对象、方法、证据与结论展开；操作流程、文件保存、调试记录及交接事项留在仓库开发文档。用户当次要求优先于本规范。

## 标题与论述

- 标题简短，准确概括本节实际内容；层级按问题之间的依赖组织。已有资料、测量和计算支撑什么，就据此命名，避免堆叠专业词或使用设问式标题。
- 开篇简要说明背景、研究对象与价值。拓展性知识服务于课题理解，不扩成与实际研究脱节的综述，也不以视频截图填充背景。
- 叙述事实简洁，分析交代前提、因果和取舍。重点处保留必要推导与解释，避免压成关键词；删除口语、提示词、修改历史、重复否定和无新增信息的过渡。
- 结论明确回答得到什么、依据什么、对设计有何影响。缺口与适用范围在相关位置集中说明，避免每段重复边界声明。

## Infra、Study 与 Alpha

| 部分 | 正文职责 |
| --- | --- |
| Infra | 给出轻量化比较必需的原结构基准、模型与接口、共同任务、材料及驱动依据、求解与测量方法，以及预先确定的共同验收条件。呈现实际基准结果；参数类别选择、候选优劣与研究方案筛选属于 Study。 |
| Study | 按设计类别依次比较候选。每阶段明确当前基准、改变的参数、共同条件、结果及选择理由；满足共同约束的最佳候选成为下一阶段基准。阶段顺序依据物理依赖确定，质量、几何或布局改变后按同一方法更新物性、载荷和结构响应。 |
| Alpha | 集中呈现最终选定的一套材料、几何、传动与连接组合及其验证结果。结论由实际候选计算支持，未形成方案时不补写预期性能。 |

通常先在一个设计类别内建立受控比较；确实存在强耦合的参数组再联合比较，说明必须联合的物理原因。避免默认展开庞大的全组合矩阵。共同负载、运动任务、末端性能及验收条件在 Infra 冻结。负载或性能要求改变时建立对应的可行参照；结构质量随需求提高而增加可以合理，比较的是同一组要求下的最小可行质量。原结构未满足新要求时，不能将其质量直接作为合格方案的优劣标准。

Infra 的部件基准包括质量、实际载荷、功能控制约束、性能裕量、减重位置收益及可改区域质量。可改区域质量与满足约束后的可行净减重分别报告。以实际响应灵敏度衡量减材消耗的性能裕量，以原件质量分布与姿态计算惯量收益；不预设通用的刚度损失百分比，也不以任意综合权重补偿承载或连接失效。完整装配的响应或功能许用值未求得时，保留未确定项，不把几何预算写成已验证的减重空间。Infra 末尾总结实际基准结论和由此确定的比较规则。

项目执行按Infra完成并冻结、Study分阶段批量计算、Alpha取最终优胜组合组织。原件局部补算服务于统一基准，不能替代整腿承力路径与连接模型的闭合。Study的批量输入继承共同条件与验收规则，每轮输出完整候选结果和优胜理由；Alpha集中报告最终组合及统一复核。复核引起的改动回到相应比较轮次重算，保持最终方案与Study证据一致。

所有可比较数值同时给出**绝对值、相对本阶段基准的变化率、相对原始 B0 的变化率**：

\[
\Delta_{\mathrm{stage}}=\frac{y_k-y_{\mathrm{ref},k}}{y_{\mathrm{ref},k}}\times100\%,\qquad
\Delta_{B0}=\frac{y_k-y_{B0}}{y_{B0}}\times100\%.
\]

注明单位、基准身份和指标优劣方向；越小越优时，负变化率表示改善。基准为零时报告绝对差。控制器固定、等预算重新调参等比较条件分别说明；同一规划规则下运动发生变化时，载荷差异不能只归因于质量。

## 理论与证据

- 先说明物理对象、载荷、支承、目标约束和自由变量，再给公式、符号、单位及适用条件。解释为何选用该关系，以及它如何支持后续判断。
- 材料指数、效率指标和边际收益放在对应设计分析中，由具体约束与几何自由度推导；通用思维方法不替代课题本身的研究问题。
- 概念加粗结合课程原文的理论层次及当前计算用途判断；用户给出的概念是示例而非封闭词表，包括：刚度/承载能力/残余强度验算，CAE模型精度对标，比性能与材料指数（E/ρ、σ/ρ、强度及扭转指数），正应力与抗弯刚度，热性能与制造状态，截面形状与抗弯效率、结构效率、承载效率与吸能，以及主动/被动集成。疲劳按应力幅、平均应力、循环次数、表面状态及环境完整论述。突出实际承担论证作用的核心概念，不逐词匹配或把所有工程术语加粗，也不机械塞入未开展的验算。尺寸优化等一般设计步骤不作概念加粗；段首小标题属于版式层级。
- 本项目理论段落可直接采用用户本人教学文章的适用原文，删去“课程笔记强调”等转述和对本人博客的不规范引用；教材、论文、标准与数据资料仍按正式来源著录。
- 原始资料、本文推导与实际计算结果清楚区分。来源就近引用并支持对应主张；内部推导不归作来源原结论，试验方法不写成已通过的实测结果。

## 图表与复核

- 结构外形、装配与零件尺寸优先使用原始标准CAD工程图或CAD软件直接导出的规范视图；不另用手绘或自制SVG轮廓代替已有工程图。原图节选保留几何、尺寸与标注，并记录原图号、版本和来源。
- 优先使用实际 CAD、测量、求解场和时程数据制作科学图表。示意图准确表达几何、受力与反馈关系，并明确其性质；不以任意插值或生成图片替代计算证据。
- 图与正文共享数据和计算口径。坐标、方向、单位、图例及标签清晰；比较图使用一致尺度，图注交代对象、条件和所示结果。数据出处与生成脚本可追溯，制作过程不进入图注。
- 连续复读全文，核对标题、变量、公式、表格与图片的一致性。保留必要理论和真实结论，删去跨章重复；计算错误需同步修正当前数据与引用位置。
