# RP1 项目推进规则

本文件保存用户明确要求的长期执行规则。继续项目时先读本文件，再读 `rp1-leg-project.md` 的当前数据状态；规则与操作记录不进入论文正文。

## 研究范围与轮次

- 当前唯一优化对象为右腿，包含归属于右腿的骨盆侧髋驱动。整机提供任务载荷与运动复核，其余结构固定。
- 每一轮按设计量类别比较整条右腿的方案配置，例如材料轮、截面与接口形状轮、材料分布与拓扑轮。矩阵必须同时列出髋、大腿、小腿、踝和足部的配置及保留条件。
- 主智能体先确定有依据的候选、参数范围与材料分配，再交计算子智能体批量求值。不要自行把新一轮缩成某一个零件的持续细分优化。
- 各轮保留所有已算候选、绝对值、相对本轮基准和B0的变化、得分及取舍理由。前轮优胜方案形成下一轮共同起点；强耦合参数才联合比较。
- 研究范围或目标发生变化时同步修改口径，不重新建立已有CAD、网格、原件物性和基准载荷。

## Infra 与验收

- Infra是本项目制定的可执行实验基础，不能仅复述开源参数。3.1确定功能边界与质量，3.2确定任务与工况集合，3.3解释指标与评分定义，3.4给出B0计算，3.5汇总由前文得到的权重、数值基准、评分和淘汰规则。
- 用户最终明确采用两级评分：先按统一指标表计算每个部位/功能组的分数 `S_g=Σ_j a_gj s_gj`，再按旧表固定的B0部位权重汇总 `S=Σ_g w_g S_g`。`w_g` 复用七个互斥功能组原质量占比；内层指标权重 `a_gj` 与外层部位权重分开登记、审阅及冻结，不根据候选排名倒推。
- 既有 `数据/Study验收/右腿/scoring.json` 的质量—配对弹性功分数只保留为局部结构效率分析，不能当成上述多指标总分，也不能据此宣布最终Alpha。新协议、计算入口及完整验算项目表存入 `数据/Infra规则/` 与 `数据/Study验收/右腿/`。
- 用户先要求九项均计分，后明确授权：缺少匹配的寿命、任务温升及有效吸能资料，本轮不考虑这三项。当前统一评分集合为质量、材料指数、承载强度、刚度、随动惯量和反射惯量；六项均有分数及权重，质量为优先项。所有候选执行同一删项规则。
- 内层权重必须由3.1–3.4的实际基准、裕量、响应灵敏度及明确的赋权方法支撑；曾拟定的35/10等比例已撤销。当前已冻结共同响应标度下的工程赋权协议，质量优先系数κ=1.05，跨材料、截面及布局轮固定；它不是物理唯一权重。实际六候选得分、区间及κ敏感性见`数据/Study验收/右腿/共同响应赋权与实际评分.json`，评分完整不等于硬约束全部通过。
- 材料指数按部件控制工况及允许改变的几何量选定，评价材料潜力；强度和刚度另评价实际结构实现程度。散热按共同热负荷/环境下的热阻或温升计分，吸能按共同冲击与允许变形/损伤条件下的有效吸能计分。其余连接、结构稳定、损伤残余承载、振动、驱动、接触和制造要求保留适用验算及硬门槛，与加权评分并行。
- 缺失指标保留空值及固定权重，不能临时重分配权重、补成基准值或满分。仅对B0预先登记的真实不适用项调整指标集合，并对所有候选一致执行。分项已知贡献不等于完整总分；硬约束失败的方案不得用其它高分补偿。
- 强度、连接承载、干涉及驱动限值属于独立约束；分数不能抵消超限。缺少响应不能填零或当通过；确实未改动的功能组才能使用单位相对贡献。
- 分组评分是明确声明的实验评价协议，不是物理上唯一的权重，也不等于真实整腿柔性输出。响应模型与共同刚性保留假设需在理论部分集中说明，避免各段重复免责声明。
- 计算与验收分别承担：计算代理提供材料/部位参数和响应；验收代理核对来源、单位、分母及限值，并按固定规则算分。主智能体决定阶段优胜与后续分配。

## 复用与并行

- 物性、完整惯量、网格、基准解及载荷优先复用。同几何换材直接更新密度比例和本构；无需重新CAD积分。
- 未变刚体物性、任务与控制时，复用已算运动响应。只对实际改变的质量分布、几何、本构或载荷作必要补算。
- 各材料/候选喂入同一计算入口，汇总至同一轮结果；不要为凑覆盖重复计算已经淘汰或不影响结论的分支。
- 在可用并发槽位内保持方案调研、计算、验收、拓扑仿真及报告职责清楚。报告代理持续完善Infra和Study，不因等待最终Alpha而停止。
- 拓扑优化的离散材料网格与可加工CAD分别记录；拓扑得分高不等于制造可行。

## 材料与 Alpha

- 材料轮应考虑铝、镁、碳纤维和钛的功能分配。碳纤维需比较纤维方向、铺层与厚度及金属安装区；钛优先与原钢制高承载件比较，不能只拿名称替换铝壳。
- 原材料牌号、热处理/供货状态、纤维方向和弹性矩阵必须对应。供应最薄厚度、加工下界与设计可用最薄厚度分别说明。
- 既有盖板铺层和足板数据应先进入同轮总表。新增纤维角等细分变量需由主智能体在整腿轮次中安排，不因一个局部结果有趣而反复转向足板。
- Study完成并汇总验收后，最后一次选择一套组合、撰写Alpha及成果结论。研究过程中不追随每个中间结果反复改旧Alpha表。
- “比较后保留原方案”和“该项尚未完成研究”必须区分，不得把任务缺失写成原结构更优的结论。
- 已有驱动完整概念实际为髋俯仰10062→6562及独立支承，并非膝电机近端搬移。膝搬移11.40%是点质量敏感性，不是完整方案结果；原布局只可作为材料/截面轮共同实验条件。布局证据见 `数据/基准资产/布局证据复核.json`。
- 用户于2026-11-09明确布局只作大致计算，不继续布局CAD。当前实际10062前移100 mm及外置AT10轮带/支承范围估算见`CAD/膝驱动近端布局/布局量级计算.json`；右腿净增0.712935–1.232660 kg，筛退当前外置方案。保留已提取资产，停止新增布局建模和网页移位外观，不能把量级计算称为新布局仿真。
- M663的BOM名为“大腿本体”，实际配准位于髋侧摆至偏航之间；报告使用“髋部连接本体”。真正右大腿下主体为M667/M481，M485/M486为盖板。不能把M663的计算覆盖写成整段大腿均已比较。
- 拓扑T1–T3是删单元的离散试算，T3静强度超限且没有可制造CAD；破面分布图已撤出报告，真实迭代曲线与数值仍保留。G2筋板虽有数值优势，但六次筋根圆角重构均未得到有效实体，不能进入已完成制造方案。

## 已有纤维角数据的范围

已有盖板0°织物/0°与45°混合、不同层数及等质量八层板的A/B/D比较。原夹层足板完成的是纤维沿前后方向的0°构造。2026-11-08准备的±5/±8/±10°输入未启动求解，不能作为已算结果；其参数调研可供正式分配的后续轮次复用。
