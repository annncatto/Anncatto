
## 拓扑优化实现

FreeCAD＋CalculiX 可作为拓扑优化的 CAD／有限元基础，材料演化需要附加程序。

- [TopoOpt 社区扩展](https://github.com/shIxx01/TopologyOptimization/tree/11756eec815839c0d2f1c34e314484578c1e7aa1)：固定 `11756eec`，2026-10-23；在已有 FreeCAD FEM 分析上设置 design／non-design／ignore、质量目标、刚度或失效指数、滤波，输出 VTK 状态及最终网格。作者的测试结果与本机验证分开记录。
- [DTU TopOpt 教学实现](https://www.topopt.mek.dtu.dk/apps-and-software/a-99-line-topology-optimization-code-written-in-matlab)：用于核对体积、柔度和灵敏度，不能代替 M231 三维装配边界。

扩展接入顺序：小算例验证 → 整腿装配与接口配准 → 原装配及各承力件基准响应 → 按主导约束确定设计域 → 多工况迭代 → 制造 CAD 重构 → 装配与全身重算。M231 为已建模局部件之一。30% 指保留 30% 的可变设计域；保留实体另计。计算记录目标、工况权重、过滤尺度、最小特征、状态材料和收敛历史。

原装配的接口和同步六分量载荷确定前，不建立假定固定面代替实际支承。接口载荷与零件自身惯性／重力按同一自由体平衡配置。CNC 重构计入刀具可达性、内圆角和装夹；增材重构计入方向、支撑、排粉、后加工及制造状态材料参数。

## CAD方案与全身载荷联算

`src/rp1-cad-variant.ts`在同一源link坐标下扣除原CAD部件，再加入候选部件，更新质量、质心和完整惯量。保留刚体必须具有物理可行惯量，源版本及原link物性必须一致；不允许与参数化尺寸/材料缩放混合。骨盆替换以functionalSide归入完整腿部功能质量；明确记录来源的驱动替换同步更新限矩、限速和折算惯量，其余关节沿用原值。该接口仅接受关节轴线、足部接触和碰撞包络保持的候选，不能自动证明结构或制造合格。

## 闭环结构载荷导出

`src/design-physics-loads.ts`在500 Hz物理步读取约束后的内部力系、刚体姿态、原点有效加速度及角速度/角加速度。加速度传感器使`mj_rnePostConstraint`在积分前执行；读取缓存场而不混用积分后的qpos/qvel。有效线加速度为a−g，结构体力取其负号。接触力含真实作用点、世界坐标力与力矩，正向定义为geom1作用于geom2。定义依据[MuJoCo 3.17接触接口](https://mujoco.readthedocs.io/en/3.17.0/APIreference/APIfunctions.html#mj-contactforce)及其版本源码。

页面勾选“记录结构载荷”后进行闭环测试，通过才提供“导出结构载荷”。导出为`anncatto.physics-structural-loads.v1`，保留输入模型、控制实现、验证结果和逐物理步记录；参数草稿与模型变化立即撤下旧导出，文件不存入localStorage。CLI等价入口：

```sh
node scripts/evaluate-lightweight-motion.mjs --input 方案输入.json --seconds 10 --include-replay --include-physics-loads --out 闭环仿真.json
```

H5R原结构含接触的5005帧记录为报告`数据/CAD方案/统一载荷/H5R-接触载荷.physics-loads.json`，SHA-256 `d5c14923b8df619df34ba44331bc426960555cf34405c44af55a7190a90f2b93`；与既有基准9项运动指标逐值相同。更早无接触的`H5R-闭环仿真.physics-loads.json`保留原SHA，供已经完成的有限元输入追溯，不覆盖。新格式含validation字段，可直接用于带符号弹性端口的逐帧足端投影。

五项结构读出验证覆盖运动摆杆、自由落体、接触反力、倾斜面摩擦/接触力矩和闭环读出前后结果不变。浏览器实际H5R导出与CLI的9项指标最大差2.9e−11；逐帧位姿、力矩、加速度按各自物理尺度交叉核验。

`数据/足板接口/calculate-foot-loads.py`进一步以原生杆端位置、官方杆长/摇臂及真实转轴建立踝杆虚功平衡，按两轴套实际径向支承和止推方向合成M658/M659安装孔群力系。记录全足总成惯性与真实地面接触；原板和其他部件的体力仍需按各自几何施加。该分配使用安装配准，并保留轴线差异产生的小残余力矩，不能用单端固支替换实际传力。
