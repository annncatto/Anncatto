# 仓库与分支

## 目录职责

| 位置 | 用途 |
| --- | --- |
| `/home/ann/Anncatto` | 本机主要检出，文章与源码维护 |
| `docs/README.md` | 工作流、证据清单与交接索引 |

## 分支职责

| 分支 | 用途 |
| --- | --- |
| `main` / `origin/main` | 已验收的公共基线；推送 `main` 会触发 Pages 发布 |
| `article/<主题>` | 一篇文章及其图表、复核脚本、来源说明 |
| `tool/<主题>` | 未完成的交互工具或功能，独立验收 |
| `local/d20-homepage` | 保留原 D20 首页工作，按原约定单独发布 |
| `buck/*` | 从 buck 取回的历史引用；用于核查和恢复 |

日常使用一个主要检出，以任务分支组织修改。完成的文章只合并该文章及必要公共改动；工具实验和原始数据分别保留。

提交文章时沿用 `<文章准确标题> YYYY-MM-DD`，日期使用 Asia/Tokyo。发布前完成构建、内部链接检查和相应页面检查；文章编辑与公开发布分别记录状态。

## 同步

```bash
git fetch origin
git status --short --branch
git switch main
git pull --ff-only origin main
git switch -c article/<主题>
```

切换前先检查未提交内容，保留其他任务的文件与暂存内容。未完成主题复用已有分支；继续时先核对公共基线变化。

工作流与来源文档统一维护在主要目录的 `docs/`，通过 Git 随分支保存。分支切换前应完成当前任务的提交或明确交接，避免依靠外部 worktree 维持独有文档。
