# Repository instructions

- Article maintenance commit subjects must use `<article title> YYYY-MM-DD`, keeping the article's exact title and using the date in Asia/Tokyo. Example: `ACT with CrossEntropyLoss 2026-10-22`.
- `main` publishes to GitHub Pages. Keep unpublished D20 homepage work on `local/d20-homepage` and exclude it from article maintenance releases.
- For course notes and screenshot-based technical blogs, follow [the course-note workflow](docs/course-note-workflow.md).
- Before continuing the local lightweight-design tool, read `docs/lightweight-tool-handoff.md`. Keep it on `draft/lightweight-design-workbench`, local-only, and leave the public homepage tools section without entries.
- Workflow and handoff documents have one canonical user-facing location: `/home/anncatto/Anncatto/docs/`. Start from [the documentation index](docs/README.md), keep those files current when working in isolated worktrees, and link users to the main-directory paths.
- For experimental articles, follow [the writing workflow](docs/experimental-article-workflow.md); for research-paper web PPTs, follow [the presentation workflow](docs/presentation-workflow.md).
