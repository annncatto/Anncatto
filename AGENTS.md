# Repository instructions

- Article maintenance commit subjects must use `<article title> YYYY-MM-DD`, keeping the article's exact title and using the date in Asia/Tokyo. Example: `ACT with CrossEntropyLoss 2026-10-22`.
- `main` publishes to GitHub Pages. Keep unpublished D20 homepage work on `local/d20-homepage` and exclude it from article maintenance releases.
- For experimental articles, follow [the writing workflow](docs/experimental-article-workflow.md). Keep drafting instructions and evidence audits out of public prose; place short observations after failure videos and unlabelled analytical paragraphs at each experiment's end. Identify the run used by every trajectory analysis.
